## 三，管道编号系统（Piping Identification）

### 3.1 管道编号格式

```
尺寸 - 流体代码 - 管线号 - 管道等级
6"-HC-1001-A1A
```

**尺寸示例**：1", 2", 4", 6", 8", 10", 12", 16", 20"
