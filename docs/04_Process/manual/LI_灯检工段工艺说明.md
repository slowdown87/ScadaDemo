## 1. 工段概述

### 1.1 功能描述

灯检工段负责对封盖完成的瓶装茶饮料进行视觉检测，采用自动灯检机配合工业相机，检测瓶内异物、液位异常、瓶身缺陷等不合格品，并进行自动剔除，确保出厂产品质量。

### 1.2 工艺流程图

```
封盖饮料 → 视觉检测 → 液位检测 → 剔除系统 → 喷码工段
              ↓
          工业相机
```

## 8. 工艺要点

### 8.1 视觉检测原理

灯检机采用机器视觉技术，通过工业相机对瓶装饮料进行多角度拍摄，结合图像处理算法识别缺陷：

```
视觉检测系统构成:

┌─────────────────────────────────────────────────────┐
│                    工业相机 (4台)                     │
│   ┌────────┐  ┌────────┐  ┌────────┐  ┌────────┐ │
│   │侧视相机│  │底视相机│  │瓶口相机│  │瓶底相机│ │
│   │ LI-102 │  │ LI-102 │  │ LI-102 │  │ LI-102 │ │
│   │   -1   │  │   -2   │  │   -3   │  │   -4   │ │
│   └────┬───┘  └────┬───┘  └────┬───┘  └────┬───┘ │
│        │            │            │            │       │
│        └────────────┴────────────┴────────────┘       │
│                         │                              │
│                         ▼                              │
│                  ┌────────────┐                        │
│                  │ 图像处理   │                        │
│                  │    PC      │                        │
│                  └─────┬──────┘                        │
│                        │                               │
└────────────────────────┼───────────────────────────────┘
                         │
                         ▼
                  ┌────────────┐
                  │ 剔除信号   │ ──▶ 气动剔除器 LI-104
                  └────────────┘
```

### 8.2 异物检测算法

**检测原理**:

| 检测方法 | 可检出异物 | 检测精度 |
|----------|------------|----------|
| 背光暗场 | 纤维、毛发、玻璃屑 | φ0.3mm |
| 前光明场 | 气泡聚集、瓶身划痕 | φ0.5mm |
| 频闪分析 | 悬浮异物(移动) | φ0.5mm |
| 液位分析 | 液位异常 | ±2mm |

**检测流程**:

```
异物检测流程:

1. 瓶流经检测工位(4个相机同时拍摄)
2. 图像传输至工控PC
3. 图像预处理(亮度校正、噪声抑制)
4. 特征提取(边缘、纹理、颜色)
5. 异物判定(与正常样本比对)
6. 缺陷分类(异物/液位/外观)
7. 剔除信号输出(<50ms)
```

### 8.3 液位检测原理

液位检测通过分析瓶底到液面的距离实现：

```
液位检测原理:

      瓶口
       │
       │ 瓶身高度 H
       │
       ▼
  ┌─────────┐
  │░░░░░░░░░│ ←── 液位 L
  │░░░░░░░░░│
  │░░░░░░░░░│
  │██████████│ ←── 瓶底
  └─────────┘
       │
       └─── 相机拍摄侧视图，计算 H-L 得到液位

合格范围: 目标液位 ±2mm
```

### 8.4 剔除控制

剔除器采用气动方式，响应时间<50ms：

```
剔除控制逻辑:

检测NG → 工控PC发出剔除信号 → 电磁阀得电 → 气缸推出 → 瓶子落入废品槽

响应时间要求:
- 检测到NG到相机输出信号: <20ms
- 信号传输到剔除器: <10ms
- 剔除动作完成: <20ms
- 总响应时间: <50ms
```

### 8.5 误剔率控制

误剔率过高达1%时需要调整检测参数：

```
误剔率调整策略:

误剔率>1% → 检查以下项目:
├── 光源亮度是否过强(过曝)
├── 检测阈值是否过严
├── 瓶子表面是否有水渍/反光
└── 相机焦距是否准确

调整后重新标定基准图像
```
