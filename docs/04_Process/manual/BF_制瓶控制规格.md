# BF_制瓶系统控制规格

> 文档版本: v1.0
> 创建日期: 2026-04-29
> 所属工段: BF (Bottle Forming)
> PLC编号: PLC-7
> 数据来源: 监控点表、吹瓶机规格

---

## 1. 概述

### 1.1 系统定位

| 项目 | 说明 |
|------|------|
| 工段名称 | PET瓶制瓶系统 |
| 控制类型 | **高速同步控制** |
| 控制重点 | 模具控制、吹瓶曲线、速度同步 |
| 重要性 | 为灌装提供空瓶，54000B/H高速线 |

### 1.2 核心技术指标

| 参数 | 设定值 | 控制精度 | 说明 |
|------|--------|----------|------|
| 制瓶速度 | 54000B/H | ±5% | 主令控制 |
| 吹瓶周期 | 66.7ms | ±1ms | 高速同步 |
| 模具温度 | 180±10℃ | ±5℃ | PID控制 |
| 吹瓶压力 | 2.5MPa | ±0.2MPa | 曲线控制 |

## 2. 工艺流程

### 2.1 P&ID流程

```
瓶胚 → 加热炉 → 吹瓶机 → 瓶检测 → 输送链 → 灌装
   │       │        │        │        │
   ▼       ▼        ▼        ▼        ▼
 BF-101  BF-102   BF-103   BF-104   BF-105
(瓶胚)  (温度)   (压力)   (检测)   (同步)
```

### 2.2 设备清单

| 设备 | 位号 | 规格 | 数量 |
|------|------|------|------|
| 瓶胚提升机 | L-101 | 5000pcs/h | 1台 |
| 加热炉 | H-401 | 24区温控 | 1台 |
| 吹瓶机 | BF-401 | 8工位 | 1台 |
| 瓶检测器 | S-401 | 光电式 | 1套 |
| 输送链 | C-401 | 54000B/H | 1套 |

## 3. 控制功能

### 3.1 吹瓶周期时序

```
周期时间: 66.7ms (对应54000B/H)

时序图:
│←──────── 66.7ms ─────────→│
│                                │
0ms ─┬── 5ms ─┬── 10ms ─┬── 15ms ─┬── 50ms ─┬── 60ms ─┬── 66.7ms ─┤
     │         │         │         │         │         │
     ├─────────┴─────────┴─────────┴─────────┴─────────┴──────────┤
     │ 瓶胚   │ 低压   │ 高压   │  保压   │  排气   │  取瓶   │
     │ 到位   │ 吹气   │ 吹气   │  保持   │  释放   │  离开   │
     └─────────┴─────────┴─────────┴─────────┴─────────┴──────────┘
```

### 3.2 吹瓶压力曲线

| 阶段 | 时间(ms) | 压力(MPa) | 说明 |
|------|----------|-----------|------|
| 预吹 | 0-15 | 0.3 | 瓶胚预成型 |
| 低压吹 | 15-30 | 0.8 | 瓶身成型 |
| 高压吹 | 30-50 | 2.5 | 瓶底成型 |
| 保压 | 50-55 | 2.5 | 保持形状 |
| 排气 | 55-60 | 0 | 释放压力 |
| 取瓶 | 60-66.7 | 0 | 输送带走 |

### 3.3 模具温度控制

| 模具区 | 温度设定 | 控制精度 | 说明 |
|--------|----------|----------|------|
| 加热区1 | 180℃ | ±5℃ | 上部 |
| 加热区2 | 180℃ | ±5℃ | 中部 |
| 加热区3 | 180℃ | ±5℃ | 下部 |
| 冷却区 | 25℃ | ±3℃ | 冷却水 |

### 3.4 速度同步

#### 3.4.1 同步控制架构

```
         PLC-6 (UHT)
              │
              │ 速度主令
              │ 54000B/H
              ▼
         PLC-7 (制瓶)
              │
              │ 本地速度主令
              │ ±5%同步
              ▼
         吹瓶机控制
              │
              │ 电子凸轮
              │ 66.7ms周期
              ▼
         8工位协调
```

#### 3.4.2 同步允许偏差

| 设备 | 同步方式 | 允许偏差 |
|------|----------|----------|
| PLC-6→PLC-7 | 速度主令 | ±5% |
| 吹瓶机内部 | 电子凸轮 | ±1ms |

### 3.5 瓶位检测与跟踪

```
瓶位跟踪系统:
- 光电传感器检测瓶胚到位
- 电子凸轮计算各工位位置
- 高速输出控制电磁阀
- 瓶号编码用于追溯
```

## 4. 顺序控制

### 4.1 启动允许条件

| 条件 | 要求 | 检查方式 | 优先级 | 不满足时 |
|------|------|----------|--------|----------|
| 急停复位 | 已复位 | 系统状态 | P0 | 禁止启动 |
| 电源正常 | 无故障 | 系统状态 | P0 | 禁止启动 |
| 气源压力 | >0.6MPa | PT-101 | P0 | 禁止启动 |
| 加热炉温度 | >170℃ | TT-102 | P1 | 禁止出瓶 |
| 无瓶胚检测 | L-101有料 | SQ-101 | P2 | 报警提示 |
| 输送链就绪 | 无故障 | 系统状态 | P1 | 检查链板 |

### 4.2 启动顺序

| 步骤 | 时间(s) | 操作 | 判定条件 | 超时处理 |
|------|---------|------|----------|----------|
| 1 | 0-10 | 检查启动允许条件 | 全部满足 | 禁止启动 |
| 2 | 0-5 | 瓶胚提升机L-101启动 | 反馈正常 | 检查电机 |
| 3 | 5-30 | 加热炉升温至设定温度 | TT-102≥170℃ | 继续等待 |
| 4 | 30-60 | 吹瓶机各工位复位 | 位置归零 | 检查原点 |
| 5 | 60-65 | 输送链启动 | 反馈正常 | 检查变频器 |
| 6 | 65-70 | 瓶胚进入加热炉 | SQ-103检测到瓶胚 | 检查光电 |
| 7 | 70+ | 吹瓶周期开始 | 连续运行 | - |

### 4.3 停机顺序

| 步骤 | 时间(s) | 操作 | 判定条件 |
|------|---------|------|----------|
| 1 | 0 | 关闭进胚阀 | 关到位 |
| 2 | 0-5 | 吹瓶机继续运行 | 处理管路中瓶子 |
| 3 | 5-10 | 吹瓶机停止 | 全部工位停止 |
| 4 | 10-15 | 输送链减速停止 | 速度=0 |
| 5 | 15+ | 加热炉保温 | 温度维持 |

### 4.4 紧急停机

| 触发条件 | 响应时间 | 动作 |
|----------|----------|------|
| 急停按钮 | <50ms | 全部停止 |
| 同步失步>±2ms | <10ms | 紧急停机 |
| 气源压力<0.5MPa | <100ms | 停吹瓶 |

### 8.2 核心功能块详细定义

#### FB_BF_Electronic_Cam (电子凸轮控制器)

```
┌─────────────────────────────────────────────────────────┐
│              FB_BF_Electronic_Cam                      │
├─────────────────────────────────────────────────────────┤
│ 功能: 电子凸轮控制，实现8工位高速同步                     │
│                                                         │
│ INPUT:                                                  │
│   - MasterSpeed : INT    // 主令速度 (B/H)            │
│   - MasterAngle : REAL   // 主令角度 (0-360°)        │
│   - CamProfile  : ARRAY  // 各工位触发角度            │
│                                                         │
│ OUTPUT:                                                 │
│   - CamAngle[8] : ARRAY  // 8工位凸轮角度            │
│   - Trigger[8]  : ARRAY  // 各工位触发信号           │
│   - SyncError   : REAL   // 同步偏差 (ms)             │
│                                                         │
│ IN_OUT:                                                │
│   - Position[8] : ARRAY  // 各工位当前位置            │
│                                                         │
│ LOGIC:                                                  │
│   // 相位间隔: 360° / 8 = 45°                        │
│   // 角度计算: CamAngle[i] = MasterAngle + i*45°     │
│   // 触发判断: Trigger[i] = (Angle >= 触发点)        │
│   // 同步偏差: SyncError = |实际角度 - 理论角度|      │
└─────────────────────────────────────────────────────────┘
```
