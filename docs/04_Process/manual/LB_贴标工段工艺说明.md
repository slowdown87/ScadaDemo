## 1. 工段概述

### 1.1 功能描述

贴标工段负责对已完成喷码的瓶装茶饮料进行标签粘贴，采用高速贴标机实现精准的标签定位和粘贴，确保标签平整、位置准确，同时具备标签检测和剔除功能。

### 1.2 工艺流程图

```
已喷码饮料 → 标签检测 → 贴标机 → 标签检测 → 装箱工段
                  ↓
              标签位置
```

## 8. 工艺要点

### 8.1 不干胶标签贴标原理

不干胶标签由三层组成：底纸、粘胶层和面材。贴标时，标签被从底纸上剥离并粘贴到产品表面：

```
不干胶标签结构:

┌────────────────────────┐
│      面材(印刷层)       │ ← 承载印刷信息
│────────────────────────│
│      粘胶层            │ ← 实现粘贴
│────────────────────────│
│      底纸(离型纸)       │ ← 保护粘胶，剥离用
└────────────────────────┘

贴标过程:
1. 标签从卷筒展开
2. 贴标头(滚筒或吸标盘)吸附标签
3. 标签从底纸剥离
4. 标签压贴在瓶身上
5. 底纸卷回废纸卷
```

### 8.2 贴标方式

根据标签位置和瓶子形状，常用贴标方式：

| 贴标方式 | 适用场景 | 特点 |
|----------|----------|------|
| 身标(环绕) | 整圈环绕瓶身 | 覆盖面积大 |
| 正背标 | 瓶身正面+背面 | 最常见方式 |
| 瓶口标 | 瓶口处 | 防伪/装饰 |
| 底部标 | 瓶底 | 产品信息 |

```
身标环绕示意:

      ┌──────────┐
      │████████████│
      │████████████│ ← 标签覆盖
      │████████████│
      │░░░░░░░░░░░│ ← 瓶身
      │░░░░░░░░░░░│
      │░░░░░░░░░░░│
      └──────────┘
```

### 8.3 标签检测原理

标签检测采用光电传感器，检测标签是否存在及位置：

```
标签检测原理:

光电传感器 LB-102:

发射器 ──────► 接收器
   │              │
   │   无标签     │  有标签
   ▼              ▼
  强信号          弱信号(遮挡)
   
标签位置检测:
- 标签前沿到达检测点 → 触发计时
- 标签后沿到达检测点 → 停止计时
- 时间差 × 瓶速 = 标签长度
- 标签位置偏差 = 实际位置 - 设定位置
```

### 8.4 贴标质量控制

| 不良类型 | 原因 | 处置 |
|----------|------|------|
| 标签歪斜 | 瓶子定位不准/贴标头磨损 | 检查定位系统和贴标头 |
| 标签气泡 | 压贴不平/压力不均 | 调整压贴滚筒压力 |
| 标签脱落 | 粘胶失效/瓶身不洁 | 检查标签质量，清洁瓶身 |
| 位置偏差 | 传感器位置偏移/瓶子间距不稳 | 调整传感器位置和输送速度 |

### 8.5 贴标流程控制

```
贴标流程:

瓶子上线 → 瓶身检测(传感器确认瓶子到位) → 标签剥离(吸标) → 贴标头压贴 → 标签检测(位置确认) → 合格品通过/不合格品剔除

关键控制点:
- 瓶子间距: 保持恒定，避免标签重叠
- 贴标速度: 与生产线速度匹配(54000瓶/h)
- 压贴力度: 均匀一致，确保标签服帖
```
