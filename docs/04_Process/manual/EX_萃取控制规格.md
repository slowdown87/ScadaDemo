## 1. 概述

### 1.1 系统定位

| 项目 | 说明 |
|------|------|
| 工段名称 | 茶叶萃取系统 |
| 控制类型 | **批次顺序控制** |
| 控制重点 | 三级逆流、温度曲线、茶水比 |
| 重要性 | 核心工艺，影响茶饮料口感和品质 |

### 1.2 核心技术指标

| 参数 | 设定值 | 控制精度 | 说明 |
|------|--------|----------|------|
| 萃取温度 | 85±5℃ | ±2℃ | PID控制 |
| 茶水比 | 1:10~1:15 | ±3% | 重量控制 |
| 萃取时间 | 15-20min | ±30s | 时间控制 |
| 茶汁浓度 | 2.0-3.0°Brix | ±0.2°Brix | 监控 |

## 3. 控制功能

### 3.1 三级逆流萃取顺序

#### 3.1.1 单罐萃取周期

| 步骤 | 时间(s) | 操作 | 判定条件 |
|------|---------|------|----------|
| 1 | 0-120 | 进茶 | 重量达到设定值 |
| 2 | 120-180 | 进热水 | 液位达到90% |
| 3 | 180-240 | 加热搅拌 | 温度达到85℃ |
| 4 | 240-1140 | 恒温萃取 | 时间达到15min |
| 5 | 1140-1320 | 茶汁泵出 | 液位<10% |
| 6 | 1320-1500 | 排渣 | 重量<50kg |

#### 3.1.2 三级逆流协调

```
时间轴: 0 ─────────────── 1h ─────────────── 2h ─────────────── 3h
        │                │                │                │
        ▼                ▼                ▼                ▼
罐1:   进茶 → 萃取 → 泵出 → 进茶 → 萃取 → 泵出 → 进茶 → ...
罐2:   进浓茶 ← 萃取 ← 泵出 ← 进浓茶 ← 萃取 ← 泵出 ← ...
罐3:   进新茶 ← 萃取 ← 泵出 ← 进新茶 ← 萃取 ← ...

茶汁流动: TK201→TK202→TK203→冷却→TK204
茶叶流动: TK203→排渣
热水流动: TK203→TK202→TK201→排渣
```

### 3.2 温度控制

#### 3.2.1 温度曲线

```
萃取温度控制:

设定温度: 85℃ (±2℃)

升温段: 0-240s
- 蒸汽阀开度: PID调节
- 升温速率: <2℃/min

恒温段: 240-1140s (15min)
- 温度波动: ±2℃
- PID参数: Kp=2.5, Ti=60s

降温段: 萃取结束前2min
- 温度降至70℃
- 准备泵出
```

#### 3.2.2 PID参数

| 回路 | 设定值 | Kp | Ti | Td | 说明 |
|------|--------|----|----|----|------|
| TIC-201 | 85℃ | 2.5 | 60s | 10s | 萃取罐1 |
| TIC-202 | 85℃ | 2.5 | 60s | 10s | 萃取罐2 |
| TIC-203 | 85℃ | 2.5 | 60s | 10s | 萃取罐3 |

### 3.3 茶水比控制

#### 3.3.1 控制逻辑

```
茶水比 = 茶叶重量 / 纯水重量

绿茶: 1:12 (茶叶:水)
红茶: 1:10
乌龙茶: 1:15

控制方式:
1. 茶叶称重: WT-201/202/203
2. 纯水计量: FT-201 (累计)
3. 比例计算: 实时显示当前比值
4. 超差报警: ±3%
```


## 4. 顺序控制

### 4.1 启动允许条件

| 条件 | 要求 | 检查方式 | 优先级 | 不满足时 |
|------|------|----------|--------|----------|
| 纯水供应 | 压力>0.1MPa | PT-201 | P0 | 禁止启动 |
| 茶叶就绪 | TH工段完成 | 信号联锁 | P1 | 等待茶叶 |
| 茶汁储罐 | 液位<80% | LT-204 | P1 | 暂停输出 |
| CIP完成 | CIP-OK=1 | 信号联锁 | P0 | 禁止启动 |
| 电源正常 | 无故障 | 系统状态 | P0 | 禁止启动 |

### 4.2 启动顺序

| 步骤 | 时间(s) | 操作 | 判定条件 | 超时处理 |
|------|---------|------|----------|----------|
| 1 | 0-30 | 检查启动允许条件 | 全部满足 | 禁止启动 |
| 2 | 0-10 | 打开纯水进水阀V-201 | 开到位 | 检查阀门 |
| 3 | 10-60 | 纯水注入TK-201至液位30% | LT-201≥30% | 检查液位 |
| 4 | 60-120 | 启动茶叶给料器进茶 | WT-201达到设定 | 检查给料器 |
| 5 | 120-180 | 继续注水至液位90% | LT-201≥90% | 检查水阀 |
| 6 | 180-240 | 启动搅拌器，启动加热 | 温度开始上升 | 检查加热 |
| 7 | 240+ | 温度达到85℃，开始萃取计时 | TT-201≥83℃ | 超时报警 |

### 4.3 停机顺序

| 步骤 | 时间(s) | 操作 | 判定条件 |
|------|---------|------|----------|
| 1 | 0-60 | 茶汁泵出至TK-204 | LT-201<10% |
| 2 | 60-120 | 排渣阀打开 | WT-201<50kg |
| 3 | 120-180 | 冲洗萃取罐 | 电导率<50μS/cm |
| 4 | 180+ | 阀门复位，待命 | 初始状态 |

### 4.4 紧急停机

| 触发条件 | 响应时间 | 动作 |
|----------|----------|------|
| 急停按钮 | <100ms | 关闭所有阀门，停止泵 |
| 温度>100℃ | <500ms | 关闭蒸汽阀，开冷却水 |
| 液位>95% | <1s | 关闭进水阀 |

| 报警号 | 描述 | 等级 | 设定值 | 处理方式 | 复位 |
|--------|------|------|--------|----------|------|

| EX-602 | 萃取温度高 | 警告 | >95℃ | 开冷却水 | 自动 |
| EX-603 | 茶水比超差 | 警告 | >±3% | 调整配比 | 手动 |
| EX-604 | 液位超限 | 警告 | >95% | 关进料阀 | 自动 |
| EX-605 | 茶汁浓度超限 | 警告 | 超出±0.5°Bx | 报警 | 手动 |
| EX-606 | 茶叶称重异常 | 警告 | >±10% | 检查给料器 | 手动 |
| EX-607 | 泵运行异常 | 故障 | - | 停机检查 | 手动 |
| EX-608 | 冷却温度高 | 警告 | >30℃ | 检查冷却系统 | 自动 |

### 5.2 联锁逻辑

| 联锁编号 | 触发条件 | 联锁动作 | 复位方式 |
|----------|----------|----------|----------|
| EX-SIL-01 | 急停按钮 | 全部停止 | 手动 |
| EX-SIL-02 | 温度>100℃ | 关闭蒸汽，开冷却 | 自动 |
| EX-SIL-03 | 液位>95% | 关闭进水阀 | 自动 |
| EX-SIL-04 | 液位<5% | 关闭出水泵 | 自动 |
