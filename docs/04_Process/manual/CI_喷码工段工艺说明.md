## 1. 工段概述

### 1.1 功能描述

喷码工段负责对检测合格的瓶装茶饮料进行生产日期、批次号等产品信息喷印，采用在线喷码设备实现高速、高清晰度的字符喷印，确保产品可追溯性。

## 8. 工艺要点

### 8.1 CIJ喷码原理

CIJ（Continuous Ink Jet，连续式喷码）是目前最常用的工业喷码技术，通过压力将墨水从喷嘴连续射出，通过充电电极和偏转电极实现字符成型：

```
CIJ喷码原理:

├─────────────────────────────────────────────────────────┤

│       │                                                 │
│       ▼                                                 │
│    ┌──────┐    ┌────────┐    ┌──────────┐              │
│    │泵压力│───▶│喷嘴微孔│───▶│ 墨水线   │              │
│    │(供给)│    │(直径μm)│    │(连续射出)│              │
│    └──────┘    └────────┘    └────┬─────┘              │
│                                    │                     │
```

### 8.2 字符形成过程

```
字符形成过程:

墨水从喷嘴射出 → 充电电极根据字符点阵充电 → 偏转电极使带电墨滴偏转 → 落到产品表面形成字符

字符矩阵示例(7×5点阵):

  "2026" 字符形成:
  
  █   █ ███ █   █ ███
  █   █   █ █   █   █
  █   █   █ █   █   █
  █   █ ███ ███ ███
  ███ █   █   █   █
  
  每个点的位置由偏转电压精确控制
```

### 8.3 喷印参数控制

喷印质量受多个参数影响：

| 参数 | 设定值 | 影响 |
|------|--------|------|
| 墨水粘度 | 2-5cP | 过高断墨，过低扩散 |
| 喷嘴直径 | 40-70μm | 决定点大小 |
| 偏转电压 | 稳定 | 影响字符精度 |
| 墨水温度 | 40±2℃ | 影响粘度稳定性 |
| 瓶速补偿 | 根据线速度 | 确保字符不变形 |

### 8.4 OCR字符检测原理

字符检测采用OCR（光学字符识别）技术：

```
OCR检测流程:

1. 相机拍摄喷印字符区域
2. 图像二值化处理
3. 字符分割(单个字符分离)
4. 特征提取(笔画、结构)
5. 与标准字符比对(数据库匹配)
6. 输出检测结果(OK/NG)

检测项目:
- 字符完整性(无缺失点)
- 字符清晰度(对比度)
- 字符位置(是否偏移)
- 内容正确性(日期/批次匹配)
```

### 8.5 常见问题及解决

| 问题 | 原因 | 解决措施 |
|------|------|----------|
| 字符模糊 | 墨水粘度不对/喷嘴堵塞 | 清洗喷嘴，调整粘度 |
| 字符缺失 | 充电电极故障/墨水断流 | 检查充电电路，疏通墨路 |
| 字符偏移 | 瓶子定位不准/编码器故障 | 检查同步信号和编码器 |
| 字符歪斜 | 喷印方向与瓶速不匹配 | 调整偏转角度或瓶速补偿 |
