## 1. 工段概述

### 1.1 功能描述

过滤工段负责将萃取液进行固液分离和精细过滤，去除茶渣、浑浊物和微生物，确保茶汤澄清透明，为后续调配和杀菌工序提供合格的原液。

### 1.2 工艺流程图

```
萃取液 → 碟式离心机 → 超滤膜组件 → 过滤液储罐
              ↓              ↓
           茶渣排出      膜反洗水
```

## 8. 工艺要点

### 8.1 碟式离心分离原理

碟式离心机通过高速旋转的碟片产生离心力，实现固液分离：

```
碟式离心原理:

┌─────────────────────────────────────────────────────────┐
│                    碟式离心机结构                        │
├─────────────────────────────────────────────────────────┤
│                                                          │
│                    旋转轴 ▼                             │
│                   ┌──────┐                             │
│                   │      │                             │
│              ┌────┴──────┴────┐                         │
│              │   碟片组(多片)   │                         │
│              │   (高速旋转)     │                         │
│              └────┬──────┬────┘                         │
│                   │      │                              │
│            固体 ◄─┴──┬───┴──► 液体(轻相)              │
│           (渣向外壁)  │      (轻相向中心)                │
│                        │                                │
│                   重相液体 ◄──┘                         │
│                                                          │
│   转速: 15000-20000 rpm                                │
│   分离因素: Δρ × ω² × r (密度差×转速²×半径)           │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 8.2 超滤膜过滤原理

超滤膜的孔径范围0.01-0.1μm，可以截留大分子蛋白质、胶体等：

```
超滤膜分离原理:

┌─────────────────────────────────────────────────────────┐
│                    超滤膜结构示意                         │
├─────────────────────────────────────────────────────────┤
│                                                          │
│   进料 ──▶ ──▶ ──▶ ──▶ ──▶ ──▶ 透过液                │
│     │                                    │              │
│     │  ┌────────────────────────────┐   │              │
│     │  │      中空纤维膜丝           │   │              │
│     │  │  ←── 0.01-0.1μm ──→       │   │              │
│     │  │                            │   │              │
│     │  └────────────────────────────┘   │              │
│     │                                    │              │
│     └──▶ ──▶ ──▶ ──▶ ──▶ ──▶ 浓缩液(大分子/胶体)   │
│                                                          │
│   截留物质:                                             │
│   - 蛋白质(分子量>10000)                                │
│   - 果胶、淀粉                                          │
│   - 细菌、胶体                                          │
│   - 透过物质: 水、小分子、糖、酸                         │
│                                                          │
└─────────────────────────────────────────────────────────┘
```

### 8.3 过滤效率控制

| 参数 | 控制范围 | 影响 |
|------|----------|------|
| 进口压力 | 0.3-0.5 MPa | 过高损坏膜 |
| 透膜压力(TMP) | 0.1-0.3 MPa | 影响通量 |
| 温度 | 50-60℃ | 影响粘度 |
| pH值 | 5-7 | 影响蛋白质稳定性 |

### 8.4 膜污染与清洗

```
膜污染类型:

1. 堵塞性污染(可逆)
   - 颗粒堵塞 → 反冲可恢复

2. 吸附性污染(部分可逆)
   - 蛋白质吸附 → 化学清洗

3. 凝胶层污染(难逆)
   - 浓差极化 → 需要强化清洗

清洗策略:
- 物理清洗: 反冲、气体反吹
- 化学清洗: NaOH碱洗(去有机物) + 酸洗(去无机垢)
```
