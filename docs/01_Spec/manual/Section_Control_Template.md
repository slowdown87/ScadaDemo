# 工段控制规格模板

> 文档版本: v1.0
> 创建日期: 2026-04-29
> 适用范围: 茶饮料生产线14个工段控制规格
> 质量标准: 与UH_UHT/PF_灌装同等详细程度

---

## 模板结构

每个工段控制规格必须包含以下章节：

### 章节1: 概述
- 1.1 系统定位表（项目、所属工段、PLC编号、控制级别、重要性）
- 1.2 核心技术指标表（参数、设定值、控制精度、控制方式）
- 1.3 控制级别定义（P0=CCP关键/P1=重要/P2=一般）

### 章节2: 工艺流程
- 2.1 P&ID流程图（ASCII图形）
- 2.2 设备清单表（位号、规格、数量）
- 2.3 生产能力（产能计算、班次产量）

### 章节3: 控制功能（核心章节）
- 3.1 [主要控制功能名称]（详细描述）
  - 3.1.1 控制架构图
  - 3.1.2 控制参数表
  - 3.1.3 控制逻辑伪代码
- 3.2 [次要控制功能]（同等详细程度）
- 3.n [其他控制功能]

### 章节4: 顺序控制
- 4.1 启动允许条件表
- 4.2 启动顺序表（步骤、时间、操作、判定条件、超时处理）
- 4.3 停机顺序表
- 4.4 顺序流程图

### 章节5: 报警与联锁
- 5.1 报警配置表（报警号、描述、等级、设定值、处理方式）
- 5.2 联锁逻辑表
- 5.3 联锁因果图
- 5.4 复位权限表

### 章节6: 数据采集
- 6.1 采集参数清单表（位号、类型、采集周期、存储周期）
- 6.2 历史数据存储表
- 6.3 统计指标计算公式

### 章节7: HMI画面
- 7.1 主画面布局（ASCII框架图）
- 7.2 趋势图画面布局
- 7.3 报警画面布局

### 章节8: 功能块规格
- 8.1 功能块清单表（名称、功能描述、版本）
- 8.2 核心功能块详细定义：
  - 输入/输出定义
  - 参数说明
  - 逻辑描述
  - 状态机定义

### 章节9: 数据块规格
- 9.1 数据块清单表
- 9.2 核心数据块结构定义

### 章节10: I/O点位
- 10.1 I/O配置表（位号、类型、地址、说明）

### 章节11: 调试要点
- 11.1 调试前检查表
- 11.2 调试步骤表
- 11.3 验收标准表

### 章节12: 附录
- 12.1 专业术语定义
- 12.2 参考标准
- 12.3 版本记录

## 质量标准要求

### 最低行数
- P0级别(CCP关键): ≥800行
- P1级别(重要): ≥600行
- P2级别(一般): ≥500行

### 必须包含
- [ ] ASCII流程图或架构图
- [ ] 完整的功能块接口定义（输入/输出/逻辑）
- [ ] 详细的控制逻辑伪代码
- [ ] 启动/停机顺序表
- [ ] 报警配置表
- [ ] I/O点位完整清单

### 禁止简化
- [ ] 禁止"详见XXX"省略详细内容
- [ ] 禁止功能块只有名称没有定义
- [ ] 禁止伪代码过于简略
- [ ] 禁止缺少调试要点

## 功能块定义标准

每个功能块必须包含：

```
┌─────────────────────────────────────────────────────────┐
│              FB_XXX_功能名称                            │
├─────────────────────────────────────────────────────────┤
│ INPUT:                                                   │
│   - 参数名 : 类型 // 参数说明                            │
│                                                          │
│ OUTPUT:                                                  │
│   - 参数名 : 类型 // 参数说明                            │
│                                                          │
│ IN_OUT:                                                  │
│   - 参数名 : 类型 // 参数说明                            │
│                                                          │
│ LOGIC:                                                   │
│   // 详细逻辑描述，每行注释                              │
└─────────────────────────────────────────────────────────┘
```
