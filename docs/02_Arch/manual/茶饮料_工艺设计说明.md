## 1. UHT无菌灌装工艺说明

```
UHT无菌灌装 vs 热灌装的区别：

热灌装：
  产品 → UHT杀菌(135℃) → 冷却(85-88℃) → 趁热灌装 → 封盖 → 倒瓶(杀菌) → 冷却 → 成品
  特点：灌装温度高，需要倒瓶杀菌，设备投资低但能耗高

UHT无菌灌装：
  产品 → UHT杀菌(135℃/15s) → 冷却(25-30℃) → 无菌储罐 → 无菌灌装 → 封盖 → 成品
  特点：室温灌装，全程无菌，保质期更长，设备投资高但品质更稳定
```

## 2. 工艺流程详图

### 2.1 水处理系统流程 (WT)

```
原水 → 原水箱 → 多介质过滤器 → 活性炭过滤器 → RO反渗透 → 离子交换柱 → UV杀菌 → 纯水储罐
         10m³     Φ1200×2400   Φ1000×2000   5m³/h     5m³/h       40W       10m³

自动反洗触发条件：
  - 多介质过滤器：压差>0.08MPa 或 运行8h
  - 活性炭过滤器：压差>0.06MPa 或 运行24h
  - RO膜：产水电导率>10μS/cm 或 运行72h
```

### 2.2 茶叶前处理流程 (TH)

```
茶叶原料 → 投料仓 → 粉碎机 → 磁选器 → 计量仓 → 输送绞龙 → 萃取系统
   500kg    500L    200kg/h   12000Gs   50kg    100kg/h
              │        │
              ▼        ▼
         袋式除尘器   金属检测器
         2000m³/h    φ1.5mm Fe
              │
              ▼
         防爆区域（粉尘浓度<50% LEL）
```

### 2.3 萃取系统流程 (EX) - 三级逆流萃取

```
茶叶 ──▶ 计量 ──▶ 萃取罐1 ──▶ 萃取罐2 ──▶ 萃取罐3 ──▶ 茶渣分离 ──▶ 冷却 ──▶ 茶汁储罐
  │       │         ▲                        │
  │       │         │                        │
  └───────┴─────────┴────────────────────────┘
                    逆流热水加热

三级逆流萃取原理：
  - 新鲜茶叶进入萃取罐1，与80-85℃热水接触进行第一次萃取
  - 萃取液进入萃取罐2，与上一级更浓的茶汁逆流换热
  - 萃取罐2的萃取液再进入萃取罐3，最终得到高浓度茶汁
  - 茶渣从萃取罐1排出
  - 热水从萃取罐3进入，逐级逆流至萃取罐1

批次参数（以2000L批次为例）：
  - 茶叶用量：约150-180kg（根据茶水比1:12-1:15）
  - 加水量：约1800-2100L
  - 萃取温度：85±2℃
  - 萃取时间：15min（保温）
  - 茶汁产量：约1600-1800L/批次
```

## 4. 卫生控制说明

### 4.1 CIP清洗程序（标准5步法）

| 步骤 | 介质 | 温度 | 时间 | 浓度 | 备注 |
|------|------|------|------|------|------|
| 1.预冲洗 | 纯水 | 85℃ | 15min | - | 去除残留产品 |
| 2.碱洗 | NaOH | 85℃ | 30min | 1.5-2.0% | 溶解有机物 |
| 3.中间冲洗 | 纯水 | 常温 | 10min | - | 冲洗碱液 |
| 4.酸洗 | HNO₃ | 60℃ | 20min | 0.8-1.5% | 去除无机物 |
| 5.最终冲洗 | 纯水 | 常温 | 10min | pH 6.5-7.0 | 中和+检测 |

## 5. 设备选型依据

### 5.1 产能匹配分析

| 工段 | 设备产能 | 瓶颈分析 |
|------|----------|----------|
| 水处理 | 5m³/h | 满足生产 |
| 萃取(批次) | 2000L/45min ≈ 2667L/h | 满足生产 |
| 过滤 | 5000L/h | 满足生产 |
| 均质 | 3000L/h | **可能瓶颈** |
| UHT | 3000L/h | **可能瓶颈** |
