# CIP清洗系统 - 电导率合格判定规格

> 文档版本: v1.0
> 创建日期: 2026-05-13
> 工段: CP (CIP Cleaning In Place)
> 用途: 最终冲洗阶段电导率检测与合格判定

---

## 1. 概述

### 1.1 电导率检测原理

电导率(Conductivity)是判断清洗效果的关键指标。清洗完成后，残留的清洗剂(碱液/酸液)会导致电导率升高，通过检测最终冲洗水的电导率可以判断清洗是否彻底。

```
清洗效果判定逻辑:

纯水冲洗 → 检测电导率 → 是否达标?
                              │
                    ┌─────────┴─────────┐
                    │                   │
                   达标               不达标
                    │                   │
                    ▼                   ▼
               清洗合格           继续冲洗/报警
            (Result=PASS)         (Result=FAIL)
```

### 1.2 电导率阈值定义

| 清洗类型 | 合格阈值 | 说明 |
|----------|----------|------|
| 纯水冲洗 | ≤50 μS/cm | 常规冲洗合格标准 |
| 碱洗后冲洗 | ≤50 μS/cm | 无残留碱液 |
| 酸洗后冲洗 | ≤50 μS/cm | 无残留酸液 |
| 消毒液后 | ≤30 μS/cm | 消毒剂残留要求更严 |
| 纯净要求 | ≤20 μS/cm | 高纯净要求 |

## 2. 判定逻辑

### 2.1 判定流程

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                      最终冲洗电导率判定流程                                      │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│  1. 冲洗开始                                                                   │
│     │                                                                          │
│     ▼                                                                          │
│  2. 检测当前电导率 (CD)                                                        │
│     │                                                                          │
│     ▼                                                                          │
│  3. CD ≤ 阈值? ──── 否 ────► 继续冲洗，计时+1                                  │
│     │                        ▲                                                 │
│    是                        │                                                 │
│     │                        │                                                 │
│     ▼                        │                                                 │
│  4. 持续检测10秒                                                             │
│     │                                                                          │
│     ▼                                                                          │
│  5. 10秒内CD持续≤阈值? ──── 否 ────► 返回步骤2                               │
│     │                        ▲                                                 │
│    是                        │                                                 │
│     │                        │                                                 │
│     ▼                        │                                                 │
│  6. 判定为合格 (PASS)                                                        │
│     │                                                                          │
│     ▼                                                                          │
│  7. 结束清洗，记录结果                                                        │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### 2.2 合格条件

| 条件 | 要求 | 说明 |
|------|------|------|
| 电导率 | CD ≤ PassConduct (默认50μS/cm) | 在阈值以下 |
| 持续时间 | 连续10秒满足 | 避免瞬时波动 |
| 采样次数 | 每秒1次 | 连续10次采样 |

### 2.3 不合格处理

| 情况 | 处理方式 | 说明 |
|------|----------|------|
| 冲洗时间<最大时间 | 继续冲洗 | 最长冲洗时间由配方决定 |
| 冲洗时间≥最大时间 | 判定不合格 | 触发报警CP-006 |
| 电导率持续超标 | 增加冲洗时间 | 可选功能 |

```pascal
// 区域数据中的判定相关字段
TYPE "UDT_ZoneData"
    STRUCT
        // ... 其他字段 ...

        // 清洗结果
        Result         : Bool;       // 清洗结果 TRUE=合格
        ResultCode     : Int;        // 结果代码
        ResultMsg      : String[50]; // 结果信息

        // ... 其他字段 ...
    END_STRUCT
END_TYPE
```

### 3.2 判定代码 (FC_StepMonitor)

```pascal
// 步骤监控 - 电导率判定部分
FUNCTION "FC_StepMonitor" : Void
VAR_INPUT
    ZoneID : Int;
END_VAR
VAR
    StepTime : Int;
    CurrentMedia : "Enum_MediaType";
    IsLastStep : Bool;
END_VAR

    // 获取当前步骤时间
    StepTime := "DB_Zone"[ZoneID].Recipe.Steps["DB_Zone"[ZoneID].CurrentStep].TargetTime;

    // ========================================================================
    // 最终冲洗电导率检测 (仅在最后一步执行)
    // ========================================================================
    IsLastStep := ("DB_Zone"[ZoneID].CurrentStep = "DB_Zone"[ZoneID].Recipe.StepCount);

    IF IsLastStep THEN
        // 获取当前电导率和合格阈值
        "DB_Zone"[ZoneID].CurrentConduct := "DB_Zone"[ZoneID].CD;

        // 获取当前介质类型
        CurrentMedia := "DB_Zone"[ZoneID].CurrentMedia;

        // 仅纯水冲洗步骤进行电导率判定
        IF CurrentMedia = "Enum_MediaType".PURE_WATER THEN
            // 检查是否达到合格电导率
            IF "DB_Zone"[ZoneID].CD <= "DB_Zone"[ZoneID].Recipe.Steps["DB_Zone"[ZoneID].CurrentStep].PassConduct THEN
                // 电导率达标
                "DB_Zone"[ZoneID].ConductOK := TRUE;
            ELSE
                // 电导率超标
                "DB_Zone"[ZoneID].ConductOK := FALSE;

                // 检查是否超时 (电导率持续超标)
                IF "DB_Zone"[ZoneID].OverTimeTimer >= StepTime THEN
                    // 判定为不合格
                    "DB_Zone"[ZoneID].Result := FALSE;
                    "DB_Zone"[ZoneID].ResultCode := 6;  // CP-006
                    "DB_Zone"[ZoneID].ResultMsg := '电导率超标';
                    "FC_TriggerAlarm"(6, "Enum_AlarmLevel".L1_WARNING, ZoneID);
                END_IF;
            END_IF;
        END_IF;
    END_IF;

    // ========================================================================
    // 步骤完成判定 (温度+时间+电导率)
    // ========================================================================
    IF "DB_Zone"[ZoneID].TempReached
    AND "DB_Zone"[ZoneID].StepTimer >= StepTime
    AND (IsLastStep = FALSE OR "DB_Zone"[ZoneID].ConductOK = TRUE) THEN
        "DB_Zone"[ZoneID].State := "Enum_CleanState".STEP_TRANSITION;
    END_IF;

END_FUNCTION
```

### 3.3 判定状态

| 状态 | 条件 | 说明 |
|------|------|------|
| ConductOK | CD ≤ 阈值 | 电导率合格 |
| ConductNG | CD > 阈值 | 电导率不合格 |
| ConductWait | 检测中 | 等待连续10秒合格 |

## 6. 报警管理

### 6.1 电导率相关报警

| 报警代码 | 描述 | 等级 | 触发条件 | 处理建议 |
|----------|------|------|----------|----------|
| CP-006 | 电导率超标 | L1 | CD > 阈值且超时 | 增加冲洗时间或终止 |
| CP-006A | 电导率偏高 | L2 | CD > 阈值的80% | 监控，可能需要延长 |
| CP-006B | 电导率异常波动 | L1 | 10秒内波动>20% | 检查传感器 |
