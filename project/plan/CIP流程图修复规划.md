### 2.2 详细组件设计

#### 2.2.1 计量泵（新增）

**位置**: 罐区下方，y=240~340

**设备清单**:
| 设备编号 | 设备名称 | 用途 | 位置 |
|---------|---------|------|------|
| P-CP06 | 碱液添加泵 | 93% NaOH配制 | x=50 |
| P-CP07 | 酸液添加泵 | 65% HNO₃配制 | x=200 |

**SVG实现**:
```tsx
<g transform="translate(50, 260)">
  <text x="0" y="-10" fontSize="12" fontWeight="bold" fill="#333">计量泵组</text>
  {['P-CP06', 'P-CP07'].map((id, index) => (
    <g key={id} transform={`translate(${index * 150}, 20)}`}>
      {/* 泵体: 椭圆形 */}
      <ellipse cx="25" cy="30" rx="22" ry="15" fill="#fff" stroke="#52c41a" strokeWidth="2" />
      <text x="25" y="35" textAnchor="middle" fontSize="12" fontWeight="bold" fill="#52c41a">P</text>
      <text x="25" y="60" textAnchor="middle" fontSize="9" fill="#333">{id}</text>
      <text x="25" y="72" textAnchor="middle" fontSize="7" fill="#666">{index === 0 ? '碱液添加' : '酸液添加'}</text>

  ))}
</g>
```

**样式**: 与清洗泵一致，但尺寸略小

#### 2.2.3 每区阀门组（新增）

**位置**: 清洗泵下方，y=540~700

**设备清单**（每区4个阀门）:
| 阀门编号 | 设备名称 | 控制 |
|---------|---------|------|
| Zx-V-01 | 进液阀 | DO |
| Zx-V-02 | 回流阀 | DO |
| Zx-V-03 | 排放阀 | DO |
| Zx-V-04 | 循环阀 | DO |

**布局**: 5个区水平排列，每区4个阀门垂直排列

**SVG实现**:
```tsx
<g transform="translate(50, 540)">
  <text x="0" y="0" fontSize="12" fontWeight="bold" fill="#333">5. 每区阀门组</text>
  <text x="0" y="12" fontSize="8" fill="#666">（进液/回流/排放/循环）</text>

  {zoneNames.map((zoneName, zoneIndex) => (
    <g key={`zone-valves-${zoneIndex}`} transform={`translate(${zoneIndex * 250}, 25)}`}>
      {/* 区域标签 */}
      <text x="60" y="0" textAnchor="middle" fontSize="10" fontWeight="bold" fill={zoneColors[zoneIndex]}>
        {zoneName}
      </text>

      {/* 4个阀门 */}
      {[
        { id: `Z${zoneIndex+1}-V-01`, name: '进液', color: '#52c41a' },
        { id: `Z${zoneIndex+1}-V-02`, name: '回流', color: '#ff9800' },
        { id: `Z${zoneIndex+1}-V-03`, name: '排放', color: '#e91e63' },
        { id: `Z${zoneIndex+1}-V-04`, name: '循环', color: '#2ecc71' }
      ].map((valve, valveIndex) => (
        <g key={valve.id} transform={`translate(0, ${valveIndex * 35})}`}>
          <rect x="0" y="0" width="120" height="28" fill="#fff" stroke={valve.color} strokeWidth="1.5" rx="3" />
          <text x="10" y="18" fontSize="9" fontWeight="bold" fill={valve.color}>{valve.id}</text>
          <text x="85" y="18" fontSize="7" fill="#666">{valve.name}</text>
          {/* 阀门状态指示 */}
          <circle cx="110" cy="14" r="5" fill={valve.color} opacity="0.5" />
        </g>
      ))}
    </g>
  ))}
</g>
```

**尺寸**: 每区阀门组宽度120px，高度28px×4=112px

## 4. 风险分析与备选方案

### 风险1: SVG空间不足
- **概率**: 高
- **影响**: 布局混乱
- **备选方案**:
  - 方案A: 增加SVG高度到950px
  - 方案B: 缩小组件尺寸（罐体从60×100缩小到50×80）
  - 方案C: 采用水平滚动布局

### 风险2: 每区阀门组复杂度过高
- **概率**: 中
- **影响**: 代码难以维护
- **备选方案**:
  - 方案A: 每区阀门折叠显示，点击展开
  - 方案B: 只显示关键阀门（进液+排放）
  - 方案C: 简化阀门图标（只显示状态颜色）

### 风险3: 管道连接错乱
- **概率**: 中
- **影响**: 流程不清晰
- **备选方案**:
  - 方案A: 使用虚线连接可选路径
  - 方案B: 使用不同颜色区分不同介质管道
  - 方案C: 添加管道编号标注

### 风险4: 实时数据绑定复杂
- **概率**: 低
- **影响**: 数据不同步
- **备选方案**:
  - 方案A: 使用React Context统一管理
  - 方案B: 每个组件独立订阅WebSocket
  - 方案C: 使用Zustand store集中管理
