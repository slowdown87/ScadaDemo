## 7. 实时数据绑定

### 7.1 罐区数据

```typescript
interface TankData {
  id: 'CP-101' | 'CP-102' | 'CP-103' | 'CP-104';
  level: number;      // LT01~04 (0-100%)
  temp: number;       // TT01~03 (0-150℃)
  conductivity: number; // CD01~02 (0-200mS/cm)
  valveStatus: boolean; // M-V-01~04
}
```

### 7.2 泵组数据

```typescript
interface PumpData {
  id: 'P-CP01' | 'P-CP02' | 'P-CP03' | 'P-CP04' | 'P-CP05';
  running: boolean;   // 运行状态
  frequency: number;  // 变频器频率 (0-50Hz)
  current: number;    // 电机电流
  fault: boolean;     // 故障状态
}
```

### 7.3 阀门数据

```typescript
interface ValveData {
  id: 'Z1-V-01' | 'Z1-V-02' | ... | 'Z5-V-04';
  open: boolean;      // 开阀状态
  position: number;   // 开度 (0-100%)
  fault: boolean;    // 故障状态
}
```

### 7.4 每区数据

```typescript
interface ZoneData {
  id: 1 | 2 | 3 | 4 | 5;
  name: string;       // '1区-水处理' / ...
  state: 'IDLE' | 'READY' | 'CLEANING' | 'PAUSE' | 'FAULT';
  temp: number;       // Zx-TT01 (0-150℃)
  conductivity: number; // Zx-CD01 (0-1000μS/cm)
  pressure: number;  // Zx-PT01 (0-1MPa)
  flow: number;       // Zx-FT01 (0-10m³/h)
  pumpRunning: boolean;
  valves: ValveData[];
}
```

## 8. 动画规格

| 动画类型 | 触发条件 | 视觉效果 | CSS/SVG实现 |
|---------|---------|---------|------------|
| 液位变化 | LT传感器变化 | 罐内液体高度变化 | SVG rect.height + fill |
| 泵旋转 | 泵运行中 | 叶轮旋转动画 | CSS @keyframes rotate |
| 阀门开闭 | 阀门命令变化 | 阀芯旋转0°↔90° | SVG transform rotate |
| 管道流动 | 阀门开+泵运行 | 箭头沿管道移动 | SVG stroke-dashoffset |
| 温度渐变 | TT传感器变化 | 罐体颜色变化 | SVG fill gradient |
| 报警闪烁 | 设备报警 | 红色闪烁 | CSS @keyframes blink |

## 9. 交互规格

| 交互动作 | 响应行为 | 技术实现 |
|---------|---------|---------|
| 单击储罐 | 弹出详情(液位/温度/历史曲线) | React Modal |
| 单击泵 | 显示泵参数(频率/电流/故障) | React Tooltip |
| 单击阀门 | 显示阀门状态(开度/命令) | React Tooltip |
| 单击清洗对象 | 聚焦该区状态 | React state + scroll |
| 悬停设备 | 显示实时数据 | SVG title / React Overlay |
