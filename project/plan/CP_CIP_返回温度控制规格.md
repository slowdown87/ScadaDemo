## 1. 概述

### 1.1 返回温度监测原理

清洗过程中，介质在换热器中被加热后送至清洗区域，冷却后返回。通过监测返回温度(TT_Return)，可以：
- 判断换热器效率
- 检测介质热量损失
- 评估清洗效果

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                         温度监测点布置                                          │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                 │
│                         换热器                                                  │
│                            │                                                    │
│       蒸汽 ──────────►  ┌───────┐                                            │
│                        │       │                                             │
│   介质入口 ───────────►│       │────► 介质出口 ──► 清洗区                      │
│   (TT_Outlet)          │       │        (TT_Outlet)                          │
│                        └───────┘                                               │
│                            │                                                   │
│                            │ 返回                                               │
│                            ▼                                                   │
│                     清洗区返回                                                 │
│                     (TT_Return)                                                │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘
```

### 1.2 温度监测参数

| 监测点 | 传感器 | 正常范围 | 异常判定 |
|--------|--------|----------|----------|
| TT_Outlet | 出口温度 | SP ± 5℃ | 低于SP 10℃持续5min |
| TT_Return | 返回温度 | TT_Outlet - 15℃内 | 温差过大/过小 |

## 2. 返回温度控制逻辑

### 2.1 控制目标

| 参数 | 值 | 说明 |
|------|-----|------|
| 目标温度 | 依配方设定 | 60-85℃ |
| 返回温度上限 | TT_Outlet + 5℃ | 异常检测 |
| 返回温度下限 | TT_Outlet - 20℃ | 异常检测 |
| 温差报警阈值 | 25℃ | 换热器效率低 |

### 2.2 温差计算

```
温差 = TT_Outlet - TT_Return

正常温差: 5-15℃
异常情况:
- 温差 < 5℃:  可能流量过大或温度传感器故障
- 温差 > 20℃: 换热器效率低或流量不足
```

### 2.3 PLC监测逻辑

```pascal
FUNCTION "FC_MonitorReturnTemp" : Void
VAR_INPUT
    ZoneID : Int;
END_VAR
VAR
    TempDiff : Real;
    TempDiffLimit : Real := 25.0;  // 温差报警阈值
END_VAR

    // 获取温度数据
    "DB_Zone"[ZoneID].TempDiff :=
        "DB_Zone"[ZoneID].TT_Outlet - "DB_Zone"[ZoneID].TT_Return;

    // 计算温差
    TempDiff := "DB_Zone"[ZoneID].TempDiff;

    // 温差过大检测 (换热器效率低)
    IF TempDiff > TempDiffLimit THEN
        "FC_TriggerAlarm"(8, "Enum_AlarmLevel".L2_INFO, ZoneID);  // CP-008
        "DB_Zone"[ZoneID].TempDiffAlarm := TRUE;
    ELSE
        "DB_Zone"[ZoneID].TempDiffAlarm := FALSE;
    END_IF;

    // 温度传感器故障检测
    IF ABS("DB_Zone"[ZoneID].TT_Outlet - "DB_Zone"[ZoneID].TT_Return) < 0.5
    AND "DB_Zone"[ZoneID].PumpCmd = TRUE THEN
        // 温差过小，可能传感器故障
        "DB_Zone"[ZoneID].TempSensorFault := TRUE;
    ELSE
        "DB_Zone"[ZoneID].TempSensorFault := FALSE;
    END_IF;

END_FUNCTION
```

## 3. 报警条件

### 3.1 返回温度相关报警

| 报警号 | 描述 | 等级 | 触发条件 | 处理建议 |
|--------|------|------|----------|----------|
| CP-008 | 管路压力/温度异常 | L2 | 温差>25℃ | 检查换热器 |
| CP-030 | 返回温度过高 | L1 | TT_Return > TT_Outlet + 5℃ | 检查阀门/流量 |
| CP-031 | 返回温度过低 | L1 | 温差 > 30℃ | 检查换热器/蒸汽 |
| CP-032 | 温度传感器故障 | L1 | 温差异常 | 检查传感器 |

### 3.2 温度趋势分析

```
正常工况温度曲线:

温度(℃)
    85 ─┼──────────────╮ TT_Outlet (目标)
        │              ╰───────╮
    70 ─┼──────────────────────╰── TT_Return
        │
    15 ─┼───────────────────────────────────── 时间
        0    5    10   15    20   25   30 (min)

温差: 约10-15℃，随时间趋于稳定
```
