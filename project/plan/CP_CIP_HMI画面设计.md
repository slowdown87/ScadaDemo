### 0.4 数字孪生功能规格

| 功能模块 | 描述 | 技术实现 |
|----------|------|----------|
| **实时同步** | PLC数据 → 3D模型 | WebSocket + Three.js |
| **设备动画** | 泵旋转/阀门开闭/液位变化 | CSS动画 + Three.js |
| **流动可视化** | 管道介质流动动画 | D3.js / SVG路径动画 |
| **状态映射** | 运行/待机/报警 ↔ 颜色/动画 | Zustand状态管理 |
| **报警高亮** | 故障设备红色闪烁 | Three.js材质切换 |
| **视角控制** | 俯视/侧视/细节/自动旋转 | OrbitControls |
| **历史回放** | 过去某时段的状态重现 | 数据重放 + 动画 |
| **预测分析** | 基于历史数据预测维护周期 | 机器学习模型 |

### 0.5 开发规范

| 规范 | 说明 |
|------|------|
| **编码规范** | ESLint + Prettier，TypeScript strict模式 |
| **组件规范** | 函数组件 + Hooks，禁止使用Class组件 |
| **命名规范** | 驼峰命名法，组件名使用PascalCase |
| **样式规范** | CSS Modules 或 Tailwind CSS，禁止内联样式 |
| **API规范** | RESTful + WebSocket，JSON格式 |
| **版本控制** | Git，提交信息使用Conventional Commits |

### 0.6 性能指标

| 指标 | 目标值 | 说明 |
|------|--------|------|
| 画面切换时间 | ≤1s | 页面首次加载 |
| 数据刷新周期 | ≤1s | 实时数据推送 |
| 报警响应时间 | ≤0.5s | 事件触发到显示 |

### 2.4 按钮功能

| 按钮 | 功能 | 条件 |
|------|------|------|
| **启动** | 启动选中区域的清洗程序 | 至少选中1区 + 配方已选择 + 系统无故障 |
| **暂停** | 暂停当前清洗 | 至少1区处于清洗中 |
| **停止** | 停止当前清洗 | 至少1区处于清洗中/暂停 |
| **跳步** | 跳到下一步 | 至少1区处于清洗中 |
