## 3. 浓度计算公式

### 3.1 稀释计算公式

```
目标浓度配比公式:

C₁ × V₁ + C₂ × V₂ = C₃ × (V₁ + V₂)

其中:
- C₁ = 原液浓度 (如浓碱 40%)
- V₁ = 原液体积 (待计算)
- C₂ = 水浓度 (0%)
- V₂ = 加水体积 (已知)
- C₃ = 目标浓度 (如 2%)

推导: V₁ = (C₃ × V₂) / (C₁ - C₃)
```

### 3.2 配置参数表

| 参数 | 碱液 | 酸液 | 说明 |
|------|------|------|------|
| 浓液浓度 | 40% (NaOH) | 65% (HNO₃) | 工业级浓液 |
| 目标浓度 | 2.0% | 1.0% | 使用浓度 |
| 初始液位 | < 30% | < 30% | 开始配置条件 |
| 目标液位 | 80% | 70% | 配置完成液位 |
| 目标温度 | 85℃ | 60℃ | 配置温度 |
| 浓度误差 | ±0.1% | ±0.1% | 合格判定 |
| 搅拌时间 | 5分钟 | 3分钟 | 混合均匀 |

### 3.3 浓度传感器

| 参数 | 值 | 说明 |
|------|-----|------|
| 型号 | 电导率式浓度计 | 通过电导率推算浓度 |
| 范围 | 0-100 mS/cm | 覆盖配置范围 |
| 精度 | ±0.5% FS | |
| 输出 | 4-20mA / HART | 连接到PLC |

## 4. PLC实现

### 4.1 配置状态机

```pascal
TYPE "Enum_ConfigState"
    IDLE        := 0;   // 待机
    FILL_WATER  := 1;   // 加水
    HEATING     := 2;   // 加热
    ADD_CHEM    := 3;   // 加药
    CIRCULATE   := 4;   // 循环搅拌
    CHECK_CONC  := 5;   // 检测浓度
    COMPLETE    := 6;   // 配置完成
    FAILED      := 7;   // 配置失败
END_TYPE

TYPE "Enum_ChemType"
    ALKALI := 1;   // 碱液
    ACID   := 2;   // 酸液
END_TYPE
```

### 4.2 配置控制函数

```pascal
FUNCTION "FC_ChemicalConfig" : Void
VAR_INPUT
    ChemType : "Enum_ChemType";  // 1=碱液, 2=酸液
    TargetConc : Real;           // 目标浓度 (%)
    TargetTemp : Real;           // 目标温度 (℃)
    TargetLevel : Real;          // 目标液位 (%)
END_VAR
VAR
    ConfigState : "Enum_ConfigState";
    CurrentConc : Real;
    CurrentTemp : Real;
    CurrentLevel : Real;
    ChemVolume : Real;           // 浓液用量 (L)
    WaterVolume : Real;          // 加水量 (L)
    TankCapacity : Real := 2000.0;  // 罐容量 (L)
END_VAR

    // 获取当前状态
    ConfigState := "Global".Config[ChemType].State;
    CurrentConc := "Global".Config[ChemType].CurrentConc;
    CurrentTemp := "Global".Config[ChemType].CurrentTemp;
    CurrentLevel := "Global".Config[ChemType].CurrentLevel;

    CASE ConfigState OF

        // ====================================================================
        // 待机状态
        // ====================================================================
        "Enum_ConfigState".IDLE:
            // 检查是否需要配置
            IF "Global".Config[ChemType].ConfigRequest THEN
                // 检查液位
                IF CurrentLevel > 30.0 THEN
                    // 液位过高，不允许配置
                    "Global".Config[ChemType].ErrorCode := 1;
                    ConfigState := "Enum_ConfigState".FAILED;
                ELSE
                    // 开始配置
                    ConfigState := "Enum_ConfigState".FILL_WATER;
                END_IF;
            END_IF;

        // ====================================================================
        // 加水状态
        // ====================================================================
        "Enum_ConfigState".FILL_WATER:
            // 打开进水阀
            "Global".Output.V101_WaterIn := TRUE;

            // 计算目标加水量
            WaterVolume := (TargetLevel / 100.0) * TankCapacity;

            // 检查液位
            IF CurrentLevel >= TargetLevel THEN
                // 液位达标，关闭进水阀
                "Global".Output.V101_WaterIn := FALSE;
                ConfigState := "Enum_ConfigState".HEATING;
            END_IF;

        // ====================================================================
        // 加热状态
        // ====================================================================
        "Enum_ConfigState".HEATING:
            // 打开蒸汽阀
            "Global".Output.SteamValve := TRUE;

            // 启动循环搅拌
            "Global".Output.V105_Circulate := TRUE;

            // 检查温度
            IF CurrentTemp >= TargetTemp THEN
                // 温度达标，关闭蒸汽阀
                "Global".Output.SteamValve := FALSE;
                ConfigState := "Enum_ConfigState".ADD_CHEM;
            END_IF;

        // ====================================================================
        // 加药状态
        // ====================================================================
        "Enum_ConfigState".ADD_CHEM:
            // 计算浓液用量
            // V_浓 = (C_目标 × V_总) / (C_浓 - C_目标)
            WaterVolume := (TargetLevel / 100.0) * TankCapacity;
            IF ChemType = "Enum_ChemType".ALKALI THEN
                // 碱液: 40%浓液
                ChemVolume := (TargetConc * WaterVolume) / (40.0 - TargetConc);
                "Global".Output.V102_AlkaliIn := TRUE;
            ELSE
                // 酸液: 65%浓液
                ChemVolume := (TargetConc * WaterVolume) / (65.0 - TargetConc);
                "Global".Output.V103_AcidIn := TRUE;
            END_IF;

            // 计量泵添加 (通过累计流量计控制)
            IF "Global".FlowMeter.ChemFlow >= ChemVolume THEN
                // 添加完成
                "Global".Output.V102_AlkaliIn := FALSE;
                "Global".Output.V103_AcidIn := FALSE;
                ConfigState := "Enum_ConfigState".CIRCULATE;
                "Global".Config[ChemType].CircTimer := 0;
            END_IF;

        // ====================================================================
        // 循环搅拌状态
        // ====================================================================
        "Enum_ConfigState".CIRCULATE:
            // 继续循环搅拌
            "Global".Output.V105_Circulate := TRUE;

            // 搅拌计时
            "Global".Config[ChemType].CircTimer := "Global".Config[ChemType].CircTimer + 1;

            // 搅拌时间到达
            IF ChemType = "Enum_ChemType".ALKALI THEN
                IF "Global".Config[ChemType].CircTimer >= 300 THEN  // 5分钟
                    "Global".Output.V105_Circulate := FALSE;
                    ConfigState := "Enum_ConfigState".CHECK_CONC;
                END_IF;
            ELSE
                IF "Global".Config[ChemType].CircTimer >= 180 THEN  // 3分钟
                    "Global".Output.V105_Circulate := FALSE;
                    ConfigState := "Enum_ConfigState".CHECK_CONC;
                END_IF;
            END_IF;

        // ====================================================================
        // 浓度检测状态
        // ====================================================================
        "Enum_ConfigState".CHECK_CONC:
            // 检测实际浓度
            IF ABS(CurrentConc - TargetConc) <= 0.1 THEN
                // 浓度合格
                ConfigState := "Enum_ConfigState".COMPLETE;
            ELSE
                // 浓度不合格
                IF CurrentConc > TargetConc THEN
                    // 浓度过高，排放部分加水稀释
                    "Global".Output.V104_Drain := TRUE;
                ELSE
                    // 浓度过低，添加浓液
                    IF ChemType = "Enum_ChemType".ALKALI THEN
                        "Global".Output.V102_AlkaliIn := TRUE;
                    ELSE
                        "Global".Output.V103_AcidIn := TRUE;
                    END_IF;
                END_IF;
            END_IF;

        // ====================================================================
        // 配置完成
        // ====================================================================
        "Enum_ConfigState".COMPLETE:
            // 记录配置完成
            "Global".Config[ChemType].LastConfigTime := "Global".System.SystemTime;
            "Global".Config[ChemType].LastConc := CurrentConc;
            "Global".Config[ChemType].LastTemp := CurrentTemp;
            "Global".Config[ChemType].ConfigRequest := FALSE;
            ConfigState := "Enum_ConfigState".IDLE;

        // ====================================================================
        // 配置失败
        // ====================================================================
        "Enum_ConfigState".FAILED:
            // 打开排放阀
            "Global".Output.V104_Drain := TRUE;
            // 等待手动复位
            IF NOT "Global".Config[ChemType].ConfigRequest THEN
                "Global".Output.V104_Drain := FALSE;
                ConfigState := "Enum_ConfigState".IDLE;
            END_IF;

    END_CASE;

    // 更新状态
    "Global".Config[ChemType].State := ConfigState;

END_FUNCTION
```

## 6. 报警与安全

### 6.1 配置相关报警

| 报警号 | 描述 | 等级 | 触发条件 | 处理建议 |
|--------|------|------|----------|----------|
| CP-021 | 碱液浓度异常 | L1 | 浓度偏差>0.5% | 检查/重新配置 |
| CP-022 | 酸液浓度异常 | L1 | 浓度偏差>0.5% | 检查/重新配置 |
| CP-023 | 碱液罐高液位 | L1 | LevelLSH=TRUE | 停止加水 |
