## ⚙️ 维护规则

### 1. 模板文件修改流程

```
1. 修改 各模块configs/*.yaml 模板文件（唯一正确入口）
2. 运行 各模块_generators/*.py 生成器
3. 检查生成的 *_auto.md 文档
4. 提交 configs/ 和 _generators/（不提交auto文件）
```

### 2. 工段控制规格文档

工段控制规格文档（WT_xxx.md等）**手动编辑**，不受生成器影响。
当设备变更时，需同步更新：
- devices.yaml（设备定义）
- 对应工段控制规格.md（控制逻辑）

### 3. 版本更新规则

| 文档类型 | 更新时机 | 版本号规则 |
| ---- | ------ | ----------- |
| 模板文件 | 修改源数据后 | v1.0 → v1.1 |
| 生成文档 | 重新生成后 | 自动更新日期 |
| 手工文档 | 内容重大变更 | v1.0 → v2.0 |
| 工段控制规格 | 控制逻辑变更 | v1.0 → v1.1 |
