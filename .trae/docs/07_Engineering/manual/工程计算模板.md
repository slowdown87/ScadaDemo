| 比热容 Cp | 3.85 kJ/(kg·K) | 4.18 kJ/(kg·K) |

#### 5.1.2 热量衡算

```
热负荷: Φ = Q × ρ × Cp × ΔT / 3600
      = (3000/3600) × 1000 × 3.85 × (135-25) / 1000
      = ___ kW

传热面积余量: 15-20%
设计热负荷: Φdesign = Φ × 1.15 = ___ kW
```

#### 5.1.3 对数平均温差

```
冷端温差: ΔT1 = T产品出 - T介质进 = 135 - 25 = 110℃
热端温差: ΔT2 = T产品进 - T介质出 = 25 - 135 = -110℃

LMTD = (ΔT1 - ΔT2) / ln(ΔT1/ΔT2)
     = (110 - (-110)) / ln(110/110)
     = 220 / ln(1)
     = → 无穷大 (逆流时等于0温差)

采用逆流布置重新计算:
ΔT1 = T热进 - T冷出 = 135 - 25 = 110℃
ΔT2 = T热出 - T冷进 = 25 - 25 = 0℃

修正后 LMTD = (110 - 0) / ln(110/0) = → 采用最小温差≥5℃原则
```

## 9. 物料平衡计算

### 9.1 产能换算

```
额定产能: 54000 B/H (54000瓶/小时)
瓶装容量: 500 ml/瓶

体积流量:
Q产品 = 54000 × 0.5 / 1000 = 27 m³/h
Q产品 = 27000 L/h

批次时间:
t批次 = V批次 / Q产品 = 2 / 27 = 0.074 h = 4.4 min

日产量:
Q日 = 54000 × 24 = 1,296,000 瓶/天
Q日 = 648 m³/天
```

### 9.2 日物料消耗

```
茶叶消耗 (绿茶):
茶水比 = 1:12
茶叶量 = 648 × 1000 / 12 / 1000 = 54 kg/h
日消耗 = 54 × 24 = 1296 kg ≈ 1.3 吨/天

糖消耗:
Brix目标 = 5.5%
糖浆浓度 = 65°Bx
糖浆量 = 648 × 5.5% / 65% = 54.9 L/h
日消耗糖 = 54.9 × 24 × 1.4 kg/L = 1844 kg ≈ 1.8 吨/天

酸消耗:
柠檬酸浓度 = 2%
pH 3.8 需酸量 ≈ 0.1%
日消耗酸 = 648 × 0.1% / 2% = 3.24 kg/h
日消耗 = 3.24 × 24 = 77.8 kg ≈ 78 kg/天
```
