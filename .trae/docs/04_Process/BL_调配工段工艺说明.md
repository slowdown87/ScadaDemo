## 1. 工段概述

### 1.1 功能描述
调配系统负责将茶汤原液与其他配料（糖浆、酸、香料等）按配方比例混合，调配出符合口感要求的半成品。主要包括调配罐、糖浆溶解、酸味调节、香料添加等。

## 4. 调配批次流程

### 4.1 标准调配流程
```
1. 茶汤注入 → 液位至50%
2. 糖浆添加 → Brix调整至目标值
3. 酸味调节 → pH调整至目标范围
4. 香料添加 → 按配方比例
5. 充分搅拌 → 混合均匀 (10min)
6. 品质检测 → 人工取样检测
7. 输送至均质 → 启动输送泵
```

### 4.2 Brix控制
```
目标Brix: 8-12°Bx (根据产品类型)

调节方式:
- Brix偏低 → 添加浓糖浆
- Brix偏高 → 添加纯水稀释
```

### 4.3 pH控制
```
目标pH: 5.0-6.5 (根据产品类型)

调节方式:
- pH偏高 → 添加柠檬酸溶液
- pH偏低 → 添加NaOH溶液 (少量)
```

## 6. 异常处置

| 异常情况 | 原因分析 | 处置措施 |
|----------|----------|----------|
| Brix偏差大 | 糖浆计量不准、茶叶浓度变化 | 重新校正仪表、调整配方 |
| pH偏差大 | 酸液浓度变化、茶叶pH波动 | 重新滴定、调整酸液 |
| 调配罐温度高 | 搅拌发热、室温高 | 开启冷却夹套 |
| 配料计量不准 | 电子秤故障、传感器漂移 | 校准电子秤、手动确认 |
