# LB_贴标系统控制规格

> 文档版本: v1.0
> 创建日期: 2026-04-29
> 所属工段: LB (Labeling 贴标)
> PLC编号: PLC-12
> 控制级别: P2 (一般)
> 重要性: 产品标识与外观质量
> 数据来源: 监控点表、设备清单、工艺需求

---

## 1. 概述

### 1.1 系统定位

| 项目 | 说明 |
|------|------|
| 工段名称 | 贴标系统 |
| 所属车间 | 包装车间 |
| PLC编号 | PLC-12 (S7-1500 CPU 1515-2 PN) |
| 控制级别 | P2 - 一般 |
| 运行模式 | 连续运行，跟随生产线速度 |
| 重要性 | 产品标识与外观质量 |
| 冗余配置 | CPU冗余 (R/H System) |

### 1.2 核心技术指标

| 参数 | 设定值 | 控制精度 | 控制方式 | 说明 |
|------|--------|----------|----------|------|
| 贴标速度 | 54000瓶/h | ±3% | 速度同步 | 与生产线同步 |
| 标签位置精度 | ±1mm | ±0.5mm | 位置控制 | 外观要求 |
| 标签剩余量 | >10% | - | 液位监控 | 预警提示 |
| 贴标合格率 | ≥99% | - | 统计监控 | 质量指标 |

### 1.3 系统组成

| 设备 | 位号 | 规格 | 数量 |
|------|------|------|------|
| 贴标机 | LB-101 | 54000B/H, ±1mm | 1台 |
| 标签检测系统 | LB-102 | 标签位置检测 | 1套 |

## 4. 报警与联锁

### 4.1 报警配置表

| 报警号 | 描述 | 等级 | 设定值 | 处理方式 |
|--------|------|------|--------|----------|
| LB-001 | 标签剩余量低 | L2 | <10% | 提示更换标签 |
| LB-002 | 标签检测报警 | L2 | 位置超差 | 剔除产品 |
| LB-003 | 贴标速度低 | L2 | <50000B/H | 检查上游 |
| LB-004 | 温度高报警 | L1 | >100℃ | 停机检查 |

### 4.2 联锁逻辑表

| 序号 | 触发条件 | 报警级别 | 联锁动作 | 复位条件 |
|------|----------|----------|----------|----------|
| LB-01 | 标签缺失检测=1 | L2 | 剔除产品 | 自动复位 |
| LB-02 | 急停触发 | L0 | 全部停止 | 复位后启动 |
