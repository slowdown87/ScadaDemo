# TH_茶叶前处理系统控制规格

> 文档版本: v2.0
> 创建日期: 2026-04-29
> 所属工段: TH (Tea Handling)
> PLC编号: PLC-2
> 控制级别: P1 (防爆区域)
> 重要性: 萃取原料预处理,影响茶叶利用率
> 防爆等级: Zone 22 (粉尘防爆)
> 数据来源: 监控点表、设备清单、防爆要求

## 1. 概述

### 1.1 系统定位

| 项目 | 说明 |
|------|------|
| 工段名称 | 茶叶前处理系统 |
| 所属车间 | 前处理车间 |
| PLC编号 | PLC-2 (S7-1500 CPU 1515-2 PN) |
| 控制级别 | P1 - 重要 |

| 冗余配置 | CPU冗余 (R/H System) |

### 1.2 核心技术指标

| 参数 | 设定值 | 控制精度 | 控制方式 | 说明 |
|------|--------|----------|----------|------|
| 粉碎粒度 | 80-100目 | ±10目 | 变频控制 | 茶叶品质 |
| 输送速度 | 可调 | ±5% | 变频控制 | 与萃取联动 |
| 粉尘浓度 | <50%LEL | 实时 | 监控联锁 | 防爆要求 |
| 除尘负压 | -2kPa | ±0.2kPa | PID控制 | 收集效果 |
| 金属检出 | Fe:φ1.5mm | - | 剔除控制 | 食品安全 |

```
【启动顺序】

| 步骤 | 时间(s) | 操作 | 判定条件 |
|------|---------|------|----------|
| 1 | 0-5 | 检查启动允许条件 | 全部满足 |
| 2 | 0-3 | 启动除尘器P-301 | 反馈运行 |
| 3 | 3-8 | 启动输送绞龙C-101 | 反馈运行 |
| 4 | 8-11 | 启动磁选器S-101 | 反馈运行 |
| 5 | 11-16 | 启动粉碎机M-101(30%) | 反馈运行 |
| 6 | 16-26 | 粉碎机升速至目标 | 转速达到 |
| 7 | 26-31 | 启动给料绞龙(30%) | 反馈运行 |
| 8 | 31+ | 正常运行 | 连续运行 |

【停机顺序】

| 步骤 | 时间(s) | 操作 | 判定条件 |
|------|---------|------|----------|
| 1 | 0 | 关闭给料绞龙 | 给料停止 |
| 2 | 0-30 | 粉碎机空载运行 | 排空物料 |
| 3 | 30-33 | 停止粉碎机M-101 | 停止 |
| 4 | 33-36 | 停止磁选器S-101 | 停止 |
```

#### 3.1.3 控制逻辑

```
┌─────────────────────────────────────────────────────────────────────────────┐
│              FB_TH_Milling_Ctrl (粉碎机控制)                                │
├─────────────────────────────────────────────────────────────────────────────┤
│ INPUT:                                                                     │
│   - Start_Command    : BOOL   // 启动命令                                 │
│   - Stop_Command     : BOOL   // 停机命令                                 │
│   - Emergency_Stop   : BOOL   // 急停                                      │
│   - DustCollector_Run: BOOL   // 除尘器运行反馈                            │
│   - Door_Closed      : BOOL   // 粉碎机门关闭                              │
│   - Dust_Level       : REAL   // 粉尘浓度(%LEL)                           │
│   - Set_Speed        : INT    // 设定转速(rpm)                            │
│   - Set_FeedRate     : REAL   // 设定给料量(kg/h)                        │
│                                                                             │
│ OUTPUT:                                                                    │
│   - Mill_Run         : BOOL   // 粉碎机运行命令                          │
│   - Mill_Speed       : INT    // 粉碎机转速设定                          │
│   - Feeder_Run       : BOOL   // 给料绞龙运行命令                        │
│   - Feeder_Speed     : REAL   // 给料速度设定                           │
│   - Alarm_MotorOverload : BOOL // 电机过载报警                          │
│   - Alarm_DustHigh   : BOOL   // 粉尘浓度高报警                        │
│   - Status           : INT    // 状态字                                 │
│                                                                             │
│ LOGIC:                                                                     │
│   // 启动允许检查                                                          │
│   Start_Permit := DustCollector_Run AND Door_Closed AND                   │
│                   (Dust_Level < 50.0) AND NOT Emergency_Stop;              │
│                                                                             │
│   // 启动序列                                                              │
│   IF Start_Command AND Start_Permit THEN                                  │
│       Mill_Run := TRUE;                                                    │
│       Mill_Speed := Set_Speed;                                            │
│       Feeder_Run := TRUE;                                                  │
│       Feeder_Speed := PID_Feeder(Set_FeedRate, Actual_FeedRate);         │
│   END_IF;                                                                  │
│                                                                             │
│   // 停机序列                                                              │
│   IF Stop_Command THEN                                                     │
│       Feeder_Run := FALSE;                                                 │
│       Wait_Timer(IN:=TRUE, PT:=T#30S);                                     │
│       IF Wait_Timer.Q THEN                                                 │
│           Mill_Run := FALSE;                                                │
│           Mill_Speed := 0;                                                  │
│       END_IF;                                                               │
│   END_IF;                                                                  │
│                                                                             │
│   // 急停                                                                  │
│   IF Emergency_Stop THEN                                                   │
│       Mill_Run := FALSE;                                                    │
│       Feeder_Run := FALSE;                                                  │
│       Mill_Speed := 0;                                                      │
│       Status := FAULT;                                                      │
│   END_IF;                                                                  │
│                                                                             │
│   // 过载保护                                                              │
│   IF Motor_Current > 6.0 THEN                                              │
│       Alarm_MotorOverload := TRUE;                                          │
│       Mill_Run := FALSE;                                                    │
│   END_IF;                                                                  │
│                                                                             │
│   // 粉尘浓度监控                                                          │
│   IF Dust_Level > 50.0 THEN                                                │
│       Alarm_DustHigh := TRUE;                                               │
│       Mill_Run := FALSE; // 降速以减少粉尘                                │
│       Mill_Speed := Mill_Speed * 0.5;                                       │
│   END_IF;                                                                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 4. 顺序控制

### 4.1 启动允许条件

| 条件 | 要求 | 检查方式 | 优先级 | 不满足时 |
|------|------|----------|--------|----------|
| 除尘器运行 | 运行中 | DI反馈 | P0 | 禁止启动 |

| 安全区域 | 无火源 | - | P1 | 禁止启动 |

### 4.2 批次投料顺序

| 步骤 | 时间(s) | 操作 | 判定条件 |
|------|---------|------|----------|
| 1 | 0-10 | 投料仓加茶叶 | 料位达到 |
| 2 | 10-15 | 启动振动给料 | 反馈正常 |
| 3 | 15+ | 连续投料到粉碎机 | 时间/重量控制 |

### 6.2 统计指标

```
产量统计:
  - 班产量 = Σ给料流量 × dt
  - 茶叶利用率 = 实际输出 / 投入量 × 100%

设备统计:
  - 运行时间 = Σ运行状态 × dt
  - 启动次数 = Σ启动信号
  - 故障次数 = Σ故障报警

安全统计:
  - 粉尘超标次数 = 浓度>50%计数
  - 金属检出次数 = 检出信号计数
```
