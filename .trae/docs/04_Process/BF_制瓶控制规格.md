# BF_制瓶系统控制规格

> 文档版本: v1.0
> 创建日期: 2026-04-29
> 所属工段: BF (Bottle Forming)
> PLC编号: PLC-7
> 数据来源: 监控点表、吹瓶机规格

---

## 1. 概述

### 1.1 系统定位

| 项目 | 说明 |
|------|------|
| 工段名称 | PET瓶制瓶系统 |
| 控制类型 | **高速同步控制** |
| 控制重点 | 模具控制、吹瓶曲线、速度同步 |
| 重要性 | 为灌装提供空瓶，54000B/H高速线 |

### 1.2 核心技术指标

| 参数 | 设定值 | 控制精度 | 说明 |
|------|--------|----------|------|
| 制瓶速度 | 54000B/H | ±5% | 主令控制 |
| 吹瓶周期 | 66.7ms | ±1ms | 高速同步 |
| 模具温度 | 180±10℃ | ±5℃ | PID控制 |
| 吹瓶压力 | 2.5MPa | ±0.2MPa | 曲线控制 |

```

   ▼       ▼        ▼        ▼        ▼
 BF-101  BF-102   BF-103   BF-104   BF-105
```

## 3. 控制功能

### 3.1 吹瓶周期时序

```
周期时间: 66.7ms (对应54000B/H)

时序图:
│←──────── 66.7ms ─────────→│
│                                │
0ms ─┬── 5ms ─┬── 10ms ─┬── 15ms ─┬── 50ms ─┬── 60ms ─┬── 66.7ms ─┤
     │         │         │         │         │         │
     ├─────────┴─────────┴─────────┴─────────┴─────────┴──────────┤
     │ 瓶胚   │ 低压   │ 高压   │  保压   │  排气   │  取瓶   │
     │ 到位   │ 吹气   │ 吹气   │  保持   │  释放   │  离开   │
     └─────────┴─────────┴─────────┴─────────┴─────────┴──────────┘
```

### 3.2 吹瓶压力曲线

| 阶段 | 时间(ms) | 压力(MPa) | 说明 |
|------|----------|-----------|------|
| 预吹 | 0-15 | 0.3 | 瓶胚预成型 |
| 低压吹 | 15-30 | 0.8 | 瓶身成型 |
| 高压吹 | 30-50 | 2.5 | 瓶底成型 |
| 保压 | 50-55 | 2.5 | 保持形状 |
| 排气 | 55-60 | 0 | 释放压力 |
| 取瓶 | 60-66.7 | 0 | 输送带走 |

### 3.3 模具温度控制

| 模具区 | 温度设定 | 控制精度 | 说明 |
|--------|----------|----------|------|
| 加热区1 | 180℃ | ±5℃ | 上部 |
| 加热区2 | 180℃ | ±5℃ | 中部 |
| 加热区3 | 180℃ | ±5℃ | 下部 |
| 冷却区 | 25℃ | ±3℃ | 冷却水 |

### 3.4 速度同步

#### 3.4.1 同步控制架构

```
         PLC-6 (UHT)
              │
              │ 速度主令
              │ 54000B/H
              ▼
         PLC-7 (制瓶)
              │
              │ 本地速度主令
              │ ±5%同步
              ▼
         吹瓶机控制
              │
              │ 电子凸轮
              │ 66.7ms周期
              ▼
         8工位协调
```

#### 3.4.2 同步允许偏差

| 设备 | 同步方式 | 允许偏差 |
|------|----------|----------|
| PLC-6→PLC-7 | 速度主令 | ±5% |
| 吹瓶机内部 | 电子凸轮 | ±1ms |

### 3.5 瓶位检测与跟踪

```
瓶位跟踪系统:
- 光电传感器检测瓶胚到位
- 电子凸轮计算各工位位置
- 高速输出控制电磁阀
- 瓶号编码用于追溯
```

## 6. 高速同步控制功能块

```
┌─────────────────────────────────────────────────────────┐
│              FB_BF_Electronic_Cam                      │
├─────────────────────────────────────────────────────────┤
│ 功能: 电子凸轮控制                                      │
│                                                         │
│ 输入:                                                  │
│   - MasterSpeed: 主令速度 (B/H)                       │
│   - MasterAngle: 主令角度 (°)                          │
│                                                         │
│ 输出:                                                  │
│   - CamAngle[8]: 8工位凸轮角度                        │
│   - Trigger[8]: 各工位触发信号                        │
│                                                         │
│ 逻辑:                                                  │
│   - 相位间隔: 360° / 8 = 45°                          │
│   - 角度计算: CamAngle[i] = MasterAngle + i*45°       │
│   - 触发判断: Trigger[i] = (Angle >= 触发点)          │
└─────────────────────────────────────────────────────────┘
```
