# UH_UHT杀菌系统控制规格

> 文档版本: v1.0
> 创建日期: 2026-04-29
> 所属工段: UH (UHT Sterilization)
> 控制级别: **CCP关键控制点**
> PLC编号: PLC-6
> 数据来源: SCADA系统功能规格说明书、联锁逻辑说明书、监控点表

---

## 1. 概述

### 1.1 目的

本文档定义茶饮料生产线UHT(Ultra High Temperature)超高温杀菌系统的控制规格，作为PLC-6程序开发、SCADA画面设计、DCS操作员操作的根本依据。

### 1.2 系统定位

| 项目 | 说明 |
|------|------|
| 工段名称 | UHT超高温杀菌 |
| 控制级别 | **CCP关键控制点** (Critical Control Point) |
| 控制重点 | 温度曲线控制、F₀值计算、产品追溯 |
| 安全等级 | SIL2 (安全完整性等级) |
| 控制响应 | ≤10ms (CCP监控) |

### 1.3 核心技术指标

| 参数 | 设定值 | 控制精度 | 监控周期 |
|------|--------|----------|----------|
| 杀菌温度 | 135℃ | ±2℃ | 10ms |
| 保温时间 | ≥15s | ±0.5s | 10ms |
| F₀值 | ≥6.0 | ±0.5 | 100ms |
| 产品流量 | 2.5-3.5m³/h | ±5% | 50ms |
| 压力控制 | 0.2-0.5MPa | ±0.02MPa | 50ms |

#### 3.1.3 温度控制逻辑

```
【温度控制逻辑伪代码】

IF TT_102 < 127℃ THEN
    // 危险温度，关闭进料阀
    UV_101 := FALSE;
    aUHT_Temp_Low := TRUE;
    Log_Alarm("CCP1温度不足，关闭进料阀");
ELSIF TT_102 < 130℃ THEN
    // 温度不足
    EH_102 := 100%; // 蒸汽全开
    aUHT_Temp_Warning := TRUE;
ELSIF TT_102 >= 130℃ AND TT_102 <= 137℃ THEN
    // 正常杀菌温度范围
    EH_102 := PID_Calc(TIC_102);
    aUHT_Temp_Warning := FALSE;
ELSE // TT_102 > 137℃
    // 温度过高
    EH_102 := EH_102 * 0.9; // 降低蒸汽
    aUHT_Temp_High := TRUE;
END_IF;
```

### 3.2 F₀值计算

#### 3.2.1 F₀定义

F₀值是衡量热杀菌效果的指标，表示在121.1℃下达到相同杀菌效果所需的时间。

```
F₀ = ∫10^((T-121.1)/10) × dt

计算周期: 100ms
判定标准:
  - F₀ ≥ 6.0: 产品合格，放行
  - F₀ < 6.0: 产品隔离，报警
```

#### 3.2.2 F₀计算功能块

```
┌─────────────────────────────────────────────────────────┐
│              FB_UHT_F0_Integrator                       │
├─────────────────────────────────────────────────────────┤
│ INPUT:                                                   │
│   - Temp     : REAL    // 当前杀菌温度(℃)               │
│   - Time_ms  : INT     // 计算周期(ms)                   │
│   - Reset    : BOOL    // 复位信号                       │
│                                                          │
│ OUTPUT:                                                  │
│   - F0_Value : REAL    // 累积F₀值                      │
│   - F0_Status: INT     // 0=计算中, 1=合格, 2=不合格    │
│                                                          │
│ IN_OUT:                                                  │
│   - Accu_Time: REAL    // 累积时间                       │
│                                                          │
│ LOGIC:                                                   │
│   F0_Increment := 10^((Temp - 121.1) / 10) * (Time_ms / 1000) │
│   Accu_Time := Accu_Time + (Time_ms / 1000)             │
│   F0_Value := F0_Value + F0_Increment                    │
│                                                          │
│   IF F0_Value >= 6.0 THEN                                │
│       F0_Status := 1; // 合格                            │
│   ELSIF Accu_Time >= 25 THEN // 超过最大处理时间          │
│       F0_Status := 2; // 不合格                          │
│   END_IF;                                                │
└─────────────────────────────────────────────────────────┘
```

    │                                        ─────

### 3.3 CCP监控

#### 3.3.1 CCP定义

| CCP点 | 控制参数 | 设定值 | 监控周期 | 响应时间 | 超出响应 |
|-------|----------|--------|----------|----------|----------|
| CCP-1 | 杀菌段温度 | ≥130℃ | 10ms | <10ms | 立即关闭进料阀 |
| CCP-2 | 保温段时间 | ≥15s | 10ms | <10ms | 延长保温或隔离 |
| CCP-3 | F₀值 | ≥6.0 | 100ms | <100ms | 产品隔离 |
| CCP-4 | 压力控制 | 0.2-0.5MPa | 50ms | <50ms | 超压泄压 |

#### 3.3.2 CCP监控功能块

```
┌─────────────────────────────────────────────────────────┐
│              FB_UHT_CCP_Monitor                          │
├─────────────────────────────────────────────────────────┤
│ INPUT:                                                   │
│   - Temp     : REAL    // 杀菌段温度                      │
│   - Pressure : REAL    // 杀菌压力                       │
│   - Flow     : REAL    // 产品流量                        │
│   - HoldTime : REAL    // 保温时间累积                    │
│   - F0_Value : REAL    // F₀累积值                       │
│                                                          │
│ OUTPUT:                                                  │
│   - CCP_Alarm     : BOOL   // CCP报警标志                │
│   - Feed_Valve    : BOOL   // 进料阀控制                 │
│   - Product_Route : INT    // 0=正常, 1=隔离, 2=报废     │
│   - Alarm_List    : ARRAY[1..4] OF INT // 报警列表       │
│                                                          │
│ LOGIC:                                                   │
│   // CCP-1: 温度监控                                     │
│   IF Temp < 127 THEN                                     │
│       Feed_Valve := FALSE;                               │
│       CCP_Alarm := TRUE;                                 │
│       Product_Route := 2; // 报废                         │
│       Alarm_List[1] := 101; // 温度危险报警              │
│   ELSIF Temp < 130 THEN                                  │
│       CCP_Alarm := TRUE;                                 │
│       Alarm_List[1] := 100; // 温度不足报警              │
│   ELSE                                                   │
│       Alarm_List[1] := 0;                               │
│   END_IF;                                                │
│                                                          │
│   // CCP-2: 保温时间监控                                  │
│   IF HoldTime < 15 AND Temp >= 130 THEN                  │
│       Alarm_List[2] := 102; // 保温时间不足               │
│   ELSE                                                   │
│       Alarm_List[2] := 0;                               │
│   END_IF;                                                │
│                                                          │
│   // CCP-3: F₀值监控                                     │
│   IF F0_Value < 6.0 AND HoldTime >= 15 THEN             │
│       Product_Route := 1; // 隔离待检                    │
│       Alarm_List[3] := 103;                             │
│   ELSE                                                   │
│       Alarm_List[3] := 0;                               │
│   END_IF;                                                │
│                                                          │
│   // CCP-4: 压力监控                                      │
│   IF Pressure > 0.5 THEN                                  │
│       UV_106 := TRUE; // 开泄压阀                        │
│       Alarm_List[4] := 104;                             │
│   ELSIF Pressure < 0.2 THEN                              │
│       Alarm_List[4] := 105;                             │
│   ELSE                                                   │
│       Alarm_List[4] := 0;                               │
│       UV_106 := FALSE;                                   │
│   END_IF;                                                │
└─────────────────────────────────────────────────────────┘
```

### 4.2 停机顺序

#### 4.2.1 正常停机步骤

| 步骤 | 时间 | 操作 | 判定条件 |
|------|------|------|----------|
| 1 | 0s | 关闭进料阀UV-101 | 关到位信号 |
| 2 | 0-30s | 等待管路产品处理完毕 | 产品全部进入保温段 |
| 3 | 30-120s | 热水循环冲刷管路 | 时间到或温度>130℃ |
| 4 | 120-180s | 逐步降温至80℃ | TIC-101≤85℃ |
| 5 | 180-240s | 关闭热水调节阀 | EH-102=0% |
| 6 | 240-300s | 压力归零 | PT-102<0.05MPa |
| 7 | 300s+ | 系统处于待命状态 | 随时可启动 |

#### 4.2.2 紧急停机

| 触发条件 | 响应时间 | 动作 | 说明 |
|----------|----------|------|------|
| 急停按钮 | <100ms | 关闭进料阀，停热水 | 强制停机 |
| 温度<127℃ | <10ms | 关闭进料阀 | CCP保护 |
| 压力>0.6MPa | <50ms | 开泄压阀 | 压力保护 |
| 流量异常 | <1s | 报警并关闭进料阀 | 流量保护 |

### 4.3 CIP联动

#### 4.3.1 CIP流程
