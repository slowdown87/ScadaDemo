## 1. 工段概述

### 1.1 功能描述
茶叶前处理系统负责将茶叶原料进行储存、粉碎、暂存，为萃取工段提供符合粒度要求的茶叶原料。

### 1.3 茶叶原料规格

| 茶类型 | 推荐水温 | 茶水比 | 备注 |
|--------|----------|--------|------|

| 乌龙茶 | 85-90℃ | 1:15-1:20 | 半发酵 |

## 3. 运行控制

### 3.1 茶叶投料控制
```
茶叶储罐液位 < 20% → 报警提示补料
茶叶储罐液位 < 10% → 粉碎机停机
```

### 3.2 粉碎机控制
```
粉碎机转速范围: 1500-2800 rpm
推荐工作转速: 2200 rpm (根据茶叶种类调整)

粉碎流量 = 转速 × 比例系数
茶叶细度由筛网目数决定 (60目标准)
```

### 3.3 输送协调
```
TH-102 (粉碎机) 运行 → TH-103 (暂存斗) 接收
TH-103 满料 → 粉碎机降速
TH-103 空料 → 粉碎机提速
```

## 5. 异常处置

| 异常情况 | 原因分析 | 处置措施 |
|----------|----------|----------|
| 粉碎机电流过大 | 茶叶结块、异物进入 | 停机检查、清理粉碎室 |
| 电机温度过高 | 负载过大、散热不良 | 降低转速、检修电机 |
| 茶叶细度不够 | 筛网破损、转速过低 | 更换筛网、调整转速 |
| 储罐液位低 | 原料用尽 | 停机报警、补充原料 |
