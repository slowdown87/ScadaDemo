# BL_调配系统控制规格

> 文档版本: v1.0
> 创建日期: 2026-04-29
> 所属工段: BL (Blending)
> PLC编号: PLC-4
> 数据来源: 监控点表、工艺配方、批次控制要求

---

## 1. 概述

### 1.1 系统定位

| 项目 | 说明 |
|------|------|
| 工段名称 | 调配系统 |
| 控制类型 | **批次顺序控制 + 串级PID** |
| 控制重点 | Brix值、pH值、批次配方 |
| 重要性 | **核心批次工段**，直接影响产品品质 |

### 1.2 核心技术指标

| 参数 | 设定值 | 控制精度 | 控制方式 |
|------|--------|----------|----------|
| Brix值 | 5.0-6.0°Bx | ±1.0°Bx | 串级PID |
| pH值 | 3.5-4.5 | ±0.5 | PID控制 |
| 液位 | 0-100% | ±2% | PID控制 |
| 配料精度 | ±2% | ±2% | 流量累计 |

## 3. 控制功能

### 3.1 批次配制顺序

| 步骤 | 操作 | 时间 | 判定条件 | 容差 |
|------|------|------|----------|------|
| 1 | 添加纯水 | 5min | 液位30% | ±2% |
| 2 | 添加茶浓缩汁 | 10min | Brix 2.5°Bx | ±0.5°Bx |
| 3 | 添加糖浆 | 5min | Brix目标值 | ±1.0°Bx |
| 4 | 添加酸液 | 3min | pH目标值 | ±0.5 |
| 5 | 添加香精 | 1min | 时间到 | - |
| 6 | 补水至目标量 | 3min | 液位100% | ±1% |
| 7 | 搅拌混合 | 15min | 时间到 | - |
| 8 | 质量确认 | 2min | Brix/pH达标 | - |
| 9 | 转移至均质 | - | 下一级就绪 | - |

### 3.2 Brix串级控制

#### 3.2.1 串级控制架构

```
                    ┌──────────────────┐
                    │  外环: Brix值    │
                    │   主控制器        │
                    │  设定: 5.5°Bx   │
                    └────────┬─────────┘
                             │
                    ┌────────┴─────────┐
                    │ 输出: 糖浆流量设定 │
                    └────────┬─────────┘
                             │
                    ┌────────▼─────────┐
                    │  内环: 流量       │
                    │   副控制器        │
                    │  反馈: FV流量    │
                    └────────┬─────────┘
                             │
                    ┌────────┴─────────┐
                    │  调节阀 FV-201    │
                    │  糖浆流量          │
                    └──────────────────┘
```

#### 3.2.2 PID参数

| 回路 | 类型 | 设定值 | Kp | Ti | Td |
|------|------|--------|----|----|-----|
| BIC-201 | 外环 | 5.5°Bx | 1.5 | 45s | 5s |
| FIC-201 | 内环 | 5.0L/min | 2.0 | 20s | 3s |

### 3.3 pH控制

#### 3.3.1 pH控制曲线

```
pH控制特点:
- 非线性: pH电极对数特性
- 滴加控制: 酸液流量调节
- 抑制振荡: 添加缓冲溶液

控制策略:
1. 预滴加: 目标pH的80%
2. 微调: PID精细调节
3. 稳定: 搅拌均匀后检测
```

#### 3.3.2 pH控制参数

| 参数 | 设定值 | Kp | Ti | Td |
|------|--------|----|----|-----|
| pH设定 | 3.8 | 2.0 | 30s | 8s |

## 6. 配方管理

### 6.1 配方结构

```yaml
blend_recipe:
  product: 绿茶饮料
  batch_size: 2000L
  
  ingredients:
    tea_concentrate:
      amount: 400L
      brix: 8.0
    sugar_syrup:
      amount: 150L
      brix: 65.0
    citric_acid:
      amount: 5kg
      concentration: 50%
    tea_aroma:
      amount: 2L
    
  targets:
    final_brix: 5.5
    final_ph: 3.8
    final_volume: 2000L
    
  sequences:
    - step: 1
      action: add_water
      target_level: 30%
      time_limit: 300s
    - step: 2
      action: add_tea_concentrate
      target_brix: 2.5
      time_limit: 600s
    - step: 3
      action: add_sugar_syrup
      target_brix: 5.5
      time_limit: 300s
    - step: 4
      action: add_citric_acid
      target_ph: 3.8
      time_limit: 180s
```
