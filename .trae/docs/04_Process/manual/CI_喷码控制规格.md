# CI_喷码系统控制规格

> 文档版本: v1.0
> 创建日期: 2026-04-29
> 所属工段: CI (Coding 喷码)
> PLC编号: PLC-11
> 控制级别: P2 (一般)
> 重要性: 产品追溯标识，不可缺少
> 数据来源: 监控点表、设备清单、工艺需求

---

## 1. 概述

### 1.1 系统定位

| 项目 | 说明 |
|------|------|
| 工段名称 | 喷码系统 |
| 所属车间 | 包装车间 |
| PLC编号 | PLC-11 (CPU 1215C) |
| 控制级别 | P2 - 一般 |
| 运行模式 | 跟随生产线速度 |
| 重要性 | 产品追溯标识，必不可少 |
| 冗余配置 | 非冗余标准CPU |

### 1.2 核心技术指标

| 参数 | 设定值 | 控制精度 | 控制方式 | 说明 |
|------|--------|----------|----------|------|
| 喷印速度 | 54000瓶/h | ±3% | 速度同步 | 与生产线同步 |
| 喷印内容 | 日期/批次/追溯码 | - | 通讯控制 | MES下发 |
| 喷印位置 | 瓶身指定位置 | ±1mm | 位置控制 | 精度要求 |
| 喷印清晰度 | 100%可读 | - | 视觉检测 | 质量指标 |

### 1.3 系统组成

| 设备 | 位号 | 规格 | 数量 |
|------|------|------|------|
| 喷码机1 | CI-101 | 小字符，54000B/H | 1台 |
| 喷码机2 | CI-102 | 小字符，54000B/H | 1台 |
| 激光喷码机 | CI-103 | 高速激光刻码 | 1台 |

### 3.2 故障切换控制

#### 3.2.1 控制逻辑

| 当前设备 | 故障时切换 | 切换方式 |
|----------|------------|----------|
| CI-101正常 | 使用CI-101 | - |
| CI-101故障 | 切换到CI-102 | 自动切换 |
| CI-102故障 | 切换到CI-103 | 自动切换 |
| CI-103故障 | 停机报警 | 急停 |
