## 3. 控制功能

### 3.1 三级逆流萃取顺序

#### 3.1.1 单罐萃取周期

| 步骤 | 时间(s) | 操作 | 判定条件 |
|------|---------|------|----------|
| 1 | 0-120 | 进茶 | 重量达到设定值 |
| 2 | 120-180 | 进热水 | 液位达到90% |
| 3 | 180-240 | 加热搅拌 | 温度达到85℃ |
| 4 | 240-1140 | 恒温萃取 | 时间达到15min |
| 5 | 1140-1320 | 茶汁泵出 | 液位<10% |
| 6 | 1320-1500 | 排渣 | 重量<50kg |

#### 3.1.2 三级逆流协调

```
时间轴: 0 ─────────────── 1h ─────────────── 2h ─────────────── 3h
        │                │                │                │
        ▼                ▼                ▼                ▼
罐1:   进茶 → 萃取 → 泵出 → 进茶 → 萃取 → 泵出 → 进茶 → ...
罐2:   进浓茶 ← 萃取 ← 泵出 ← 进浓茶 ← 萃取 ← 泵出 ← ...
罐3:   进新茶 ← 萃取 ← 泵出 ← 进新茶 ← 萃取 ← ...

茶汁流动: TK201→TK202→TK203→冷却→TK204
茶叶流动: TK203→排渣
热水流动: TK203→TK202→TK201→排渣
```

### 3.2 温度控制

#### 3.2.1 温度曲线

```
萃取温度控制:

设定温度: 85℃ (±2℃)

升温段: 0-240s
- 蒸汽阀开度: PID调节
- 升温速率: <2℃/min

恒温段: 240-1140s (15min)
- 温度波动: ±2℃
- PID参数: Kp=2.5, Ti=60s

降温段: 萃取结束前2min
- 温度降至70℃
- 准备泵出
```

#### 3.2.2 PID参数

| 回路 | 设定值 | Kp | Ti | Td | 说明 |
|------|--------|----|----|----|------|
| TIC-201 | 85℃ | 2.5 | 60s | 10s | 萃取罐1 |
| TIC-202 | 85℃ | 2.5 | 60s | 10s | 萃取罐2 |
| TIC-203 | 85℃ | 2.5 | 60s | 10s | 萃取罐3 |

### 3.3 茶水比控制

#### 3.3.1 控制逻辑

```
茶水比 = 茶叶重量 / 纯水重量

绿茶: 1:12 (茶叶:水)
红茶: 1:10
乌龙茶: 1:15

控制方式:
1. 茶叶称重: WT-201/202/203
2. 纯水计量: FT-201 (累计)
3. 比例计算: 实时显示当前比值
4. 超差报警: ±3%
```

### 3.4 批次管理器

```
┌─────────────────────────────────────────────────────────┐
│              FB_EX_Batch_Manager                        │
├─────────────────────────────────────────────────────────┤
│ 功能: 管理三级逆流萃取批次                               │
│                                                         │
│ 批次状态:                                               │
│   - WAIT: 等待中                                        │
│   - FILLING: 进料中                                     │
│   - HEATING: 升温中                                     │
│   - EXTRACTING: 萃取中                                  │
│   - PUMPING: 泵出中                                     │
│   - DISCHARGING: 排渣中                                 │
│   - CLEANING: 清洗中                                    │
│                                                         │
│ 协调逻辑:                                               │
│   - 三罐交替运行                                         │
│   - 上一级泵出完成 = 下一级进料条件                      │
│   - 保持连续茶汁供应                                     │
└─────────────────────────────────────────────────────────┘
```

## 6. 顺序控制时序图

```
三级逆流萃取时序:

T=0:00    罐1开始进茶，罐2泵出茶汁到罐3，罐3进新热水
T=0:02    罐1进茶完成，开始进热水
T=0:03    罐2泵出完成，开始排渣
T=0:05    罐3进热水完成，开始萃取
T=0:07    罐1热水进完，开始升温萃取
T=0:10    罐3排渣完成，开始进新茶
T=0:12    罐1温度达到85℃，开始计时
T=0:15    罐3新茶进完，开始进热水
T=0:17    罐2开始进罐1萃出液
T=0:20    罐3温度达到85℃，开始计时
         ... (持续循环)
```
