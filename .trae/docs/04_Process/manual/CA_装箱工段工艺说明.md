## 1. 工段概述

### 1.1 功能描述

装箱工段负责将已完成贴标的瓶装茶饮料进行纸箱包装，采用自动装箱机实现瓶组的自动抓取、纸箱成型和产品装箱，确保包装牢固、整齐。

### 1.2 工艺流程图

```
已贴标饮料 → 纸箱成型 → 装箱机 → 封箱机 → 膜包工段
                 ↓
            12瓶/箱
```

## 8. 工艺要点

### 8.1 装箱流程

自动装箱机将瓶组抓取并放入纸箱，主要分为三个阶段：

├─────────────────────────────────────────────────────────────┤

│  1. 纸箱成型                                                  │
│  ┌────────────────────────────────┐                         │
│  │ 平板纸箱 → 折叠成型 → 底部粘合  │                         │
│  └────────────────────────────────┘                         │
│                        ↓                                     │
│  2. 瓶组抓取                                                  │
│  ┌────────────────────────────────┐                         │

### 8.2 装箱机抓取原理

抓取机构采用真空吸盘方式，根据瓶型设计吸盘阵列：

```
抓取机构示意:

    吸盘阵列 (4×3=12个)

    ┌────┬────┬────┐
    │ ○  │ ○  │ ○  │ ← 第一排
    ├────┼────┼────┤
    │ ○  │ ○  │ ○  │ ← 第二排
    ├────┼────┼────┤
    │ ○  │ ○  │ ○  │ ← 第三排
    ├────┼────┼────┤
    │ ○  │ ○  │ ○  │ ← 第四排
    └────┴────┴────┘

    每个 ○ 代表一个真空吸盘
    12个瓶子 = 12个吸盘

真空系统:
真空泵 → 真空电磁阀 → 吸盘 → 吸附瓶子 → 抓取完成
```

### 8.4 缺瓶检测原理

装箱前通过光电传感器检测瓶子数量，确保每箱瓶数正确：

```
缺瓶检测原理:

光电传感器 CA-101-CT 安装在瓶组进入装箱工位前:

    瓶子排列 → | ○ ○ ○ ○ | ○ ○ ○ ○ | ○ ○ ○ ○ | → 装箱工位
                  ↓       ↓       ↓
              传感器1  传感器2  传感器3

计数逻辑:
- 每个传感器检测到瓶子+1
- 3个传感器 × 4次检测 = 12个瓶子
- 计数<12 → 缺瓶报警 → 禁止装箱
```

### 8.5 装箱质量控制

| 不良类型 | 原因 | 处置 |
|----------|------|------|
| 缺瓶装箱 | 瓶子倾倒/计数错误 | 检查输送和计数系统 |
| 纸箱变形 | 吸盘力度不均/纸箱质量问题 | 检查吸盘和纸箱 |
| 封箱不牢 | 温度低/胶量不足 | 检查热熔胶温度和胶量 |
| 瓶子破损 | 抓取力度过大/瓶间距小 | 调整真空度和瓶间距 |
