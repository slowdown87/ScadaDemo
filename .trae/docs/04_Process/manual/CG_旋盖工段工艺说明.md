## 1. 工段概述

### 1.1 功能描述

旋盖工段负责对灌装完成的瓶装茶饮料进行瓶盖旋盖密封，通过精确的扭矩控制确保瓶盖拧紧到位，防止泄漏，同时配备瓶盖消毒系统确保封盖过程的无菌性。

### 1.2 工艺流程图

```
瓶装饮料 → 瓶盖消毒 → 旋盖机 → 扭矩检测 → 灯检工段
              ↓
          60℃以上
```

## 8. 工艺要点

### 8.1 旋盖原理

**扭矩-盖型匹配原理**:

旋盖是通过旋转瓶盖使其与瓶口螺纹啮合，产生轴向压紧力实现密封。扭矩过小导致密封不严，扭矩过大导致瓶盖变形或开启困难。

```
扭矩-密封关系曲线:

    扭矩(Nm)
    0.7 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐ 过扭矩区(盖变形/开启困难)
                                    │
    0.5 ─ ─ ─ ─ ─ ─ ─ ─ ● ─ ─ ─ ─┼─ 最佳扭矩点(0.3-0.7Nm范围)
                                    │
    0.3 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┤ 欠扭矩区(密封不严)
                                    │
    0.1 ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┴─────────────────────────
                                    ↑
                              密封临界点
```

**扭矩控制策略**:

| 扭矩区间 | 判定 | 处置 |
|----------|------|------|
| <0.3Nm | 过低 | 剔除+报警 |
| 0.3-0.7Nm | 合格 | 通过 |
| >0.7Nm | 过高 | 剔除+报警 |

### 8.2 瓶盖消毒原理

瓶盖消毒采用热力杀菌方式，通过蒸汽或热水将瓶盖加热至60℃以上，保持一定时间以杀灭微生物。

```
消毒温度曲线:

100℃ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┐
                               │ 峰值温度
 85℃ ─ ─ ─ ─ ─●───────────────┤
                ↑
 60℃ ─ ─ ─ ─ ─┼─●──────────────┴── 消毒温度下限(≥60℃)
                │ ↑
 40℃ ─ ─ ─ ─ ─┼─┴──────────────┐
               └────────────────┘
               0    5    10   (min)
                 消毒时间
```

### 8.3 瓶盖供给控制

瓶盖通过振荡盘供料，通过光电传感器检测瓶盖数量和到位状态：

```
瓶盖供给控制逻辑:
                
瓶盖料位<20% → 低料位报警(提示补充)
瓶盖料位<10% → 停止旋盖，等待补料

光电传感器检测:
- 瓶盖到位 → 允许旋盖
- 瓶盖缺失 → 暂停，等待瓶盖
```

### 8.4 速度同步控制

旋盖机速度必须与灌装机严格同步，避免瓶盖错位或积压：

```
同步控制:

PF灌装机 ──速度信号(±1ms)──▶ CG旋盖机
                                         │
PF灌装机 ──瓶位信号(±1ms)──▶ CG旋盖机 ◀─── 瓶盖供给
                                         │
                                         ▼
                                    扭矩检测
                                         │
                                         ▼
                               合格品 → LI灯检
```

**同步精度要求**: ±1ms
