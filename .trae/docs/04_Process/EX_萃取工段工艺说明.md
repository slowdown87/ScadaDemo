## 1. 工段概述

### 1.1 功能描述
萃取系统负责将茶叶与纯水按一定比例混合，在特定温度下进行萃取，得到茶汤原液。主要包括萃取罐、冷却器、茶渣分离和茶汤储罐。

## 4. 运行控制

### 4.1 批次萃取流程
```
1. 茶叶投入 → 纯水注入 → 加热至萃取温度
2. 保温萃取 → 搅拌混合 → 静置
3. 茶渣分离 → 茶汤冷却 → 送至储罐
4. 茶渣排放 → 设备清洗 → 准备下一批
```

### 4.2 温度控制
```
EX-101 (95℃): 夹套蒸汽加热, PID控制
EX-102 (90℃): 夹套蒸汽加热, PID控制
EX-103 (85℃): 夹套蒸汽加热, PID控制

萃取温度偏差: ±3℃
```

### 4.3 茶汤品质控制
```
茶汤温度 > 40℃ → 加速冷却 (品质保护)
茶汤pH: 5.5-6.5 (最佳口感)
```

## 6. 异常处置

| 异常情况 | 原因分析 | 处置措施 |
|----------|----------|----------|
| 萃取温度偏差大 | 蒸汽压力不稳、温控故障 | 检查蒸汽系统、手动调节 |
| 茶汤浑浊 | 茶叶细度不够、分离效果差 | 检查粉碎机、分离器 |
| 储罐温度高 | 制冷故障、存放超时 | 启动应急冷却、尽快使用 |
| 批次产量不足 | 茶叶量不够、萃取时间短 | 增加茶叶量、延长萃取 |
