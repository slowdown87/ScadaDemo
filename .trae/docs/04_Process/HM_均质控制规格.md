## 1. 概述

### 1.1 系统定位

| 项目 | 说明 |
|------|------|
| 工段名称 | 均质系统 |
| 控制类型 | 连续控制 + 顺序控制 |
| 控制重点 | 均质压力、进料温度 |
| 重要性 | 影响产品口感和稳定性 |

### 1.2 核心技术指标

| 参数 | 设定值 | 控制精度 | 说明 |
|------|--------|----------|------|
| 均质压力 | 20-25MPa | ±1MPa | PID控制 |
| 进料温度 | 65±5℃ | ±2℃ | PID控制 |
| 出料温度 | <70℃ | ±5℃ | 监控 |
| 振动值 | <4.5mm/s | 监控 | 轴承状态 |

## 3. 控制功能

### 3.1 均质压力控制

#### 3.1.1 压力控制回路

```
                    ┌──────────────────┐
                    │   压力设定值      │
                    │   25MPa          │
                    └────────┬─────────┘
                             │
                    ┌────────┴─────────┐
                    │  PID控制器        │
                    │  Kp=2.0, Ti=20s │
                    └────────┬─────────┘
                             │
                    ┌────────┴─────────┐
                    │  高压调节阀        │
                    │  XV-301          │
                    └────────┬─────────┘
                             │
                    ┌────────┴─────────┐
                    │  压力变送器        │
                    │  PT-301          │
                    └──────────────────┘
```

#### 3.1.2 压力控制参数

| 参数 | 设定值 | Kp | Ti | Td |
|------|--------|----|----|-----|
| 均质压力 | 25MPa | 2.0 | 20s | 5s |

#### 3.1.3 压力范围控制

| 压力范围 | 控制动作 | 说明 |
|----------|----------|------|
| <18MPa | 报警 | LL停机 |
| 18-20MPa | 报警提示 | 压力不足 |
| 20-25MPa | PID自动 | 正常范围 |
| 25-27MPa | 报警提示 | 压力偏高 |
| >27MPa | 报警停机 | HH保护 |

### 3.2 阀门顺序控制

#### 3.2.1 启动顺序

| 步骤 | 时间(s) | 操作 | 判定条件 |
|------|---------|------|----------|
| 1 | 0-5 | 确认阀门状态 | 初始状态 |
| 2 | 5-10 | 打开BV-107 (30%) | 开到位 |
| 3 | 10-30 | 启动高压泵P-301 (30%) | 反馈正常 |
| 4 | 30-60 | 缓慢升压至15MPa | 压力达到 |
| 5 | 60-120 | 启动进料泵P-302 | 流量建立 |
| 6 | 120-180 | 升压至目标值25MPa | 压力稳定 |
| 7 | 180+ | 正常运行 | - |

#### 3.2.2 停机顺序

| 步骤 | 时间(s) | 操作 | 判定条件 |
|------|---------|------|----------|
| 1 | 0 | 停止进料泵P-302 | 停止 |
| 2 | 0-30 | 高压泵降压至5MPa | 压力达到 |
| 3 | 30-60 | 打开BV-109 (泄压) | 开到位 |
| 4 | 60-90 | 压力归零 | PT<0.5MPa |
| 5 | 90-120 | 停止高压泵P-301 | 停止 |
| 6 | 120+ | 阀门复位 | 初始状态 |

#### 3.2.3 阀门定义

| 阀门 | 位号 | 功能 |
|------|------|------|
| BV-107 | 进料调节阀 | 流量调节 |
| BV-108 | 均质阀 | 压力调节 |
| BV-109 | 泄压阀 | 停机泄压 |

### 3.3 温度控制

| 位置 | 设定值 | 控制方式 |
|------|--------|----------|
| 预热段 | 65±5℃ | PID |
| 出料段 | <70℃ | 监控报警 |

### 3.4 振动监控

| 监控内容 | 设定值 | 处理方式 |
|----------|--------|----------|
| 振动速度 | <4.5mm/s | 正常 |
| 振动报警 | >4.5mm/s | 预警 |
| 振动停机 | >7.1mm/s | 紧急停机 |
