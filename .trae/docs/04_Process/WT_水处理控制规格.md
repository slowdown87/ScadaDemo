# WT_水处理系统控制规格

> 文档版本: v2.0

> 所属工段: WT (Water Treatment)

## 1. 概述

### 1.1 系统定位

| 项目 | 说明 |
|------|------|
| 工段名称 | 水处理系统 |
| 所属车间 | 公用工程车间 |

| 重要性 | 基础配套，为萃取、调配等工段提供纯水 |

### 1.2 核心技术指标

| 参数 | 设定值 | 控制精度 | 控制方式 | 说明 |
|------|--------|----------|----------|------|
| 产水流量 | 2.5m³/h | ±5% (±0.125m³/h) | PID控制 | 变频泵 |
| 产水电导率 | <10μS/cm | ±0.5μS/cm | 监控报警 | - |
| RO前压力 | 0.6-0.8MPa | ±0.02MPa | 变频调节 | 膜保护 |
| 储罐液位 | 30-90% | ±5% | PID控制 | - |
| 反洗压差 | >0.08MPa | 触发 | 自动 | 过滤器 |
| 再生电导率 | >10μS/cm | 触发 | 报警提示 | 离子交换 |

#### 3.1.2 反洗触发逻辑

```
┌─────────────────────────────────────────────────────────────────────────────┐
│              FB_WT_MF_Wash (反洗触发与顺序控制)                             │
├─────────────────────────────────────────────────────────────────────────────┤
│ INPUT:                                                                     │
│   - Trigger_DiffPress : BOOL   // 压差触发信号                            │
│   - Trigger_Timer     : BOOL   // 定时触发信号                            │
│   - Trigger_Manual    : BOOL   // 手动触发信号                            │
│   - Auto_Mode         : BOOL   // 自动模式                                │
│   - Manual_Step       : INT    // 手动步骤选择 (1-10)                     │
│   - Safety_OK         : BOOL   // 安全条件满足                            │
│                                                                             │
│ OUTPUT:                                                                    │
│   - Wash_Active       : BOOL   // 反洗进行中                              │
│   - Current_Step      : INT    // 当前步骤 (1-10)                          │
│   - Step_Timer        : REAL   // 步骤计时 (s)                             │
│   - Valve_Open[12]    : ARRAY  // 阀门开命令                              │
│   - Pump_Start        : BOOL   // 泵启动命令                              │
│   - Wash_Complete     : BOOL   // 反洗完成                                 │
│   - Alarm_WashFail    : BOOL   // 反洗失败报警                            │
│                                                                             │
│ IN_OUT:                                                                    │
│   - DiffPress[4]      : ARRAY  // 4台过滤器压差                          │
│   - Step_Counter      : INT    // 步骤计数器                              │
│                                                                             │
│ LOGIC:                                                                     │
│   // 反洗触发判断                                                          │
│   IF Auto_Mode THEN                                                        │
│       Trigger := (DiffPress[1] > 0.08) OR                                 │
│                   (DiffPress[2] > 0.08) OR                                 │
│                   (DiffPress[3] > 0.08) OR                                 │
│                   (DiffPress[4] > 0.08) OR                                 │
│                   (Trigger_Timer AND Hour >= 8);                          │
│   ELSE                                                                     │
│       Trigger := Trigger_Manual;                                           │
│   END_IF;                                                                  │
│                                                                             │
│   // 反洗顺序执行                                                          │
│   CASE Step_Counter OF                                                     │
│       0: // 等待触发                                                        │
│           IF Trigger AND Safety_OK THEN                                    │
│               Step_Counter := 1;                                           │
│           END_IF;                                                          │
│                                                                             │
│       1: // 关闭进水阀 (10s)                                               │
│           Valve_Open[1] := FALSE; // 进水阀关                            │
│           IF Step_Timer >= 10 THEN                                         │
│               Step_Counter := 2;                                           │
│           END_IF;                                                          │
│                                                                             │
│       2: // 打开反洗进水阀 (10s)                                           │
│           Valve_Open[2] := TRUE;  // 反洗进水阀开                         │
│           IF Step_Timer >= 10 THEN                                         │
│               Step_Counter := 3;                                           │
│           END_IF;                                                          │
│                                                                             │
│       3: // 启动反洗泵,开度30% (5s)                                        │
│           Pump_Start := TRUE;                                              │
│           Pump_Speed := 30;                                                │
│           IF Step_Timer >= 5 THEN                                          │
│               Step_Counter := 4;                                           │
│           END_IF;                                                          │
│                                                                             │
│       4: // 反洗流量控制 (270s)                                            │
│           Pump_Speed := PID(DiffPress:=12, Setpoint:=12); // 12m³/h      │
│           IF Step_Timer >= 270 THEN                                        │
│               Step_Counter := 5;                                           │
│           END_IF;                                                          │
│                                                                             │
│       5: // 停止反洗泵 (10s)                                                │
│           Pump_Start := FALSE;                                             │
│           IF Step_Timer >= 10 THEN                                         │
│               Step_Counter := 6;                                           │
│           END_IF;                                                          │
│                                                                             │
│       6: // 关闭反洗进水阀,打开正洗排水 (10s)                              │
│           Valve_Open[2] := FALSE;                                          │
│           Valve_Open[3] := TRUE;  // 正洗排水阀开                         │
│           IF Step_Timer >= 10 THEN                                         │
│               Step_Counter := 7;                                           │
│           END_IF;                                                          │
│                                                                             │
│       7: // 打开进水阀,正洗流量8m³/h (270s)                                │
│           Valve_Open[1] := TRUE;                                           │
│           Pump_Start := TRUE;                                              │
│           Pump_Speed := 67; // 8/12×100%                                  │
│           IF Step_Timer >= 270 THEN                                        │
│               Step_Counter := 8;                                           │
│           END_IF;                                                          │
│                                                                             │
│       8: // 检查电导率,判断正洗效果 (30s)                                  │
│           IF Conductivity < 100 THEN                                       │
│               Step_Counter := 9;                                           │
│           ELSIF Step_Timer >= 30 THEN                                      │
│               Alarm_WashFail := TRUE; // 电导率不合格                      │
│               Step_Counter := 9;                                           │
│           END_IF;                                                          │
│                                                                             │
│       9: // 关闭排水阀,恢复运行 (10s)                                       │
│           Valve_Open[3] := FALSE;                                          │
│           Pump_Start := FALSE;                                             │
│           IF Step_Timer >= 10 THEN                                         │
│               Step_Counter := 0;                                           │
│               Wash_Complete := TRUE;                                       │
│           END_IF;                                                          │
│                                                                             │
│   END_CASE;                                                                │
│                                                                             │
│   // 步骤计时                                                              │
│   IF Step_Counter > 0 THEN                                                 │
│       Step_Timer := Step_Timer + 0.1; // 100ms扫描周期                    │
│   ELSE                                                                     │
│       Step_Timer := 0;                                                     │
│   END_IF;                                                                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### 3.2.2 回收率控制

```
回收率 = 产水流量 / (产水流量 + 浓水流量) × 100%

目标: 75% (节能与膜寿命平衡)

控制策略:
- 产水流量固定: 2.5m³/h (由配方/需求决定)
- 浓水流量调节: 0.83m³/h (维持75%回收率)
- 浓水阀开度PID调节
```

#### 3.2.3 膜污染监控

```
膜污染指数 (SDI) 监测:
- 测定时间: 15分钟
- 测定频率: 每4小时一次
- SDI值 < 5: 正常运行
- SDI值 5-10: 加强监测
- SDI值 > 10: 化学清洗

化学清洗触发:
- 压差增加20%
- 产水量下降15%
- 运行满500h
```

### 6.3 统计指标

```
产能统计:
  - 日产水量 = Σ产水流量 × dt
  - 月产水量 = Σ日产水量
  - 产水率 = 产水量 / (产水量+浓水量) × 100%

设备统计:
  - 运行时间 = Σ运行状态 × dt
  - 启动次数 = Σ启动信号
  - 反洗次数 = Σ反洗完成
  - 故障次数 = Σ故障报警

水质统计:
  - 平均电导率 = Σ电导率 / n
  - 超标次数 = 电导率>10μS/cm计数
  - 合格率 = (总次数-超标次数) / 总次数 × 100%
```
