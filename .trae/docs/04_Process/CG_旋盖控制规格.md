#### 3.1.3 控制逻辑伪代码

```
PROGRAM FB_Capping_Torque
VAR_INPUT
    iTorque_PV : REAL;      // 扭矩过程值
    iTorque_SP : REAL := 0.5; // 扭矩设定值 0.5Nm
    iAuto_Mode : BOOL;
    iStart : BOOL;
    iStop : BOOL;
END_VAR

VAR_OUTPUT
    qTorque_Output : REAL;
    qTorque_OK : BOOL;
    qAlarm_L : BOOL;
    qAlarm_H : BOOL;
    qReject : BOOL;
END_VAR

VAR
   积分项 : REAL;
   上一次误差 : REAL;
END_VAR

// 扭矩控制逻辑
IF iAuto_Mode AND iStart THEN
    // PID计算
    误差 := iTorque_SP - iTorque_PV;
    比例项 := Kp * 误差;
    积分项 := 积分项 + Ki * 误差 * 采样时间;
    微分项 := Kd * (误差 - 上一次误差) / 采样时间;

    qTorque_Output := 比例项 + 积分项 + 微分项;
    qTorque_Output := LIMIT(0.0, 100.0, qTorque_Output);

    // 报警判定
    qAlarm_L := iTorque_PV < 0.3;  // 扭矩低报警
    qAlarm_H := iTorque_PV > 0.7;  // 扭矩高报警

    // 扭矩合格判定
    qTorque_OK := (iTorque_PV >= 0.3) AND (iTorque_PV <= 0.7);

    // 剔除信号 (扭矩不合格)
    qReject := NOT qTorque_OK;

    上一次误差 := 误差;
ELSE
    qTorque_Output := 0;
    qTorque_OK := FALSE;
    qAlarm_L := FALSE;
    qAlarm_H := FALSE;
    qReject := FALSE;
END_IF;
```

## 4. 顺序控制

### 4.1 启动允许条件

| 条件 | 要求 | 检查点 | 说明 |
|------|------|--------|------|
| 上游灌装就绪 | 灌装线运行 | DI点 | 速度同步信号 |
| 瓶盖供应正常 | 消毒器有料位 | DI点 | 料位开关 |
| 消毒温度达标 | ≥60℃ | CG-101-TT | 温度联锁 |
| 急停复位 | 无急停触发 | DI点 | 安全联锁 |
| 门安全联锁 | 门关闭 | DI点 | 设备安全 |

### 4.2 启动顺序表

| 步骤 | 时间 | 操作 | 判定条件 | 超时处理 |
|------|------|------|----------|----------|
| 1 | 0s | 检查启动允许条件 | 全部满足 | 禁止启动 |
| 2 | 0-5s | 启动瓶盖消毒器 | UV运行 | 报警提示 |
| 3 | 5-10s | 等待消毒温度≥60℃ | CG-101-TT≥60 | 等待最长30s |
| 4 | 10-15s | 接收上游速度信号 | PF速度有效 | 报警提示 |
| 5 | 15s+ | 启动旋盖电机 | 扭矩跟踪正常 | 联锁停机 |

### 4.3 停机顺序表

| 步骤 | 时间 | 操作 | 判定条件 | 说明 |
|------|------|------|----------|------|
| 1 | 0s | 接收停机命令 | - | 正常停机或急停 |
| 2 | 0-2s | 通知上游减速 | PF降速信号 | 同步停机 |
| 3 | 2-5s | 旋盖速度降至50% | 扭矩衰减 | 缓冲停机 |
| 4 | 5s | 停止旋盖电机 | 电机停止 | 惯性停机 |
| 5 | 5s+ | 关闭瓶盖消毒器 | UV停止 | 设备保护 |

│   - 积分项 : REAL        // PID积分项                  │
│   - 上一次误差 : REAL     // 上次采样误差               │

│   - Kp : REAL := 2.0    // 比例增益                    │

# DB100 CG_Config
CG_Config = Struct {
    Torque_SP : REAL := 0.5;        # 扭矩设定值 Nm

    Torque_Max : REAL := 0.7;      # 高报警限
    Speed_Min : REAL := 50000;     # 最低速度
    Speed_Max : REAL := 58000;     # 最高速度

CG_Status = Struct {
    Mode : INT;                     # 0=停机, 1=运行
    Torque_PV : REAL;              # 当前扭矩
    Speed_PV : REAL;               # 当前速度
    Output : REAL;                  # 输出值
    Count_Total : UDINT;           # 总瓶数
    Count_Reject : UDINT;          # 剔除数
    Count_Metal : UDINT;           # 金属检测数
}

## 11. 调试要点

### 11.1 调试前检查表

- [ ] PLC通讯正常
- [ ] 扭矩传感器校准完成
- [ ] 速度编码器接线正确
- [ ] 变频器参数设置正确
- [ ] 金属检测机灵敏度测试通过
- [ ] 剔除电磁阀动作正常
- [ ] 急停回路测试正常

### 11.2 调试步骤表

| 步骤 | 内容 | 判定标准 |
|------|------|----------|
| 1 | 空载运行测试 | 电机启动正常，无异响 |
| 2 | 扭矩传感器校准 | 零点准确，线性度<1% |
| 3 | PID参数整定 | 扭矩跟踪误差<0.05Nm |
| 4 | 速度同步测试 | 偏差<±3% |
| 5 | 金属检测测试 | 标准试块100%检出 |
| 6 | 剔除动作测试 | 响应时间<50ms |
| 7 | 72h连续运行 | 无异常停机 |

### 11.3 验收标准表

| 项目 | 标准 | 测试方法 |
|------|------|----------|
| 扭矩控制精度 | ±0.05Nm | 标准扭矩仪对比 |
| 扭矩合格率 | ≥99.5% | 统计24h数据 |
| 剔除准确率 | 100% | 测试样品验证 |
| 同步精度 | ±3% | 对比PF/PG速度 |
| 急停响应 | <100ms | 触发到停机 |
