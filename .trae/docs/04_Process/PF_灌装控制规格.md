> 文档版本: v1.0
> 创建日期: 2026-04-29
> 所属工段: PF (Packing/Filling)
> 控制级别: 超高速同步控制

---

## 1. 概述

### 1.1 目的

本文档定义茶饮料生产线灌装系统的控制规格，作为PLC-8程序开发、SCADA画面设计、DCS操作员操作的根本依据。灌装系统是整条生产线中对同步控制要求最高的工段，需要实现72ms周期的精确灌装控制。

### 1.2 系统定位

| 项目 | 说明 |
|------|------|
| 工段名称 | PET瓶灌装 |
| 控制级别 | **超高速同步控制** |
| 控制重点 | 72ms周期同步、液位精度±1.5%、无菌控制 |
| 安全等级 | SIL2 |
| 同步精度 | ±1ms |

### 1.3 核心技术指标

| 参数 | 设定值 | 控制精度 | 同步周期 |
|------|--------|----------|----------|
| 灌装速度 | 50000-54000 B/H | ±3% | 72ms/瓶 |
| 灌装容量 | 500ml/瓶 | ±1.5% (±7.5ml) | - |
| 灌装周期 | 72ms | ±0.5ms | - |
| 液位精度 | ±1.5% | PID控制 | 10ms |
| 同步偏差 | <1ms | 实时校正 | 10ms |

### 3.3 单阀控制逻辑

```
┌─────────────────────────────────────────────────────────────┐
│              FB_PF_Filling_Valve (单阀控制器)               │
├─────────────────────────────────────────────────────────────┤
│ INPUT:                                                     │
│   - FillCommand    : BOOL   // 灌装命令                    │
│   - BottlePresent   : BOOL   // 瓶到位信号                  │
│   - LevelSetpoint   : REAL   // 液位设定值 (500ml)         │
│   - OpenDelay       : INT    // 开阀延迟 (ms)               │
│   - CloseDelay      : INT    // 关阀延迟 (ms)               │
│                                                             │
│ OUTPUT:                                                    │
│   - ValvePosition   : REAL   // 阀门开度 (0-100%)          │
│   - ActualVolume    : REAL   // 实际灌装量 (ml)             │
│   - FillTime        : INT    // 灌装时间 (ms)              │
│   - FillComplete    : BOOL   // 灌装完成标志                │
│   - BottleAbsence   : BOOL   // 缺瓶报警                    │
│                                                             │
│ IN_OUT:                                                    │
│   - LevelCurrent    : REAL   // 当前液位                    │
│                                                             │
│ LOGIC:                                                     │
│   // 瓶位检测                                               │
│   IF NOT BottlePresent THEN                                 │
│       ValvePosition := 0;                                   │
│       BottleAbsence := TRUE;                               │
│       RETURN;                                              │
│   END_IF;                                                  │
│                                                             │
│   // 开阀                                                   │
│   IF FillCommand AND BottlePresent THEN                     │
│       Start_Timer(OpenDelay);                              │
│       IF Timer >= OpenDelay THEN                           │
│           ValvePosition := 100; // 全开                    │
│           Start_Timer(FillTimer);                          │
│       END_IF;                                              │
│   END_IF;                                                  │
│                                                             │
│   // 液位控制关阀                                          │
│   IF LevelCurrent >= LevelSetpoint THEN                    │
│       ValvePosition := 0;                                  │
│       FillComplete := TRUE;                                │
│       ActualVolume := LevelCurrent;                        │
│       FillTime := Timer.Value;                             │
│   END_IF;                                                  │
│                                                             │
│   // 超时保护                                              │
│   IF Timer >= 70ms THEN                                    │
│       ValvePosition := 0;                                 │
│       FillComplete := TRUE;                                │
│       ActualVolume := LevelCurrent;                        │
│   END_IF;                                                  │
└─────────────────────────────────────────────────────────────┘
```

### 4.3 主令速度控制

```
┌─────────────────────────────────────────────────────────────┐
│              FB_PF_Speed_Master (速度主令)                  │
├─────────────────────────────────────────────────────────────┤
│ INPUT:                                                     │
│   - TargetSpeed  : INT    // 目标速度 (B/H)                 │
│   - AccelRate    : REAL   // 加速率 (%/s)                  │
│   - DecelRate    : REAL   // 减速率 (%/s)                  │
│   - Enable       : BOOL   // 使能信号                       │
│                                                             │
│ OUTPUT:                                                    │
│   - ActualSpeed  : INT    // 实际速度 (B/H)                 │
│   - CycleTime    : INT    // 当前周期 (ms)                  │
│   - MasterAngle  : REAL   // 主令角度 (0-360°)             │
│   - SyncStatus   : INT    // 0=同步, 1=加速, 2=减速        │
│                                                             │
│ IN_OUT:                                                    │
│   - CurrentSpeed : INT    // 当前速度                       │
│                                                             │
│ LOGIC:                                                     │
│   // 速度计算                                              │
│   IF Enable THEN                                           │
│       IF TargetSpeed > CurrentSpeed THEN                   │
│           CurrentSpeed := CurrentSpeed + AccelRate;        │
│           SyncStatus := 1;                                 │
│       ELSIF TargetSpeed < CurrentSpeed THEN               │
│           CurrentSpeed := CurrentSpeed - DecelRate;        │
│           SyncStatus := 2;                                 │
│       ELSE                                                 │
│           SyncStatus := 0;                                 │
│       END_IF;                                              │
│   ELSE                                                     │
│       CurrentSpeed := 0;                                   │
│       SyncStatus := 0;                                     │
│   END_IF;                                                  │
│                                                             │
│   // 周期计算                                              │
│   IF CurrentSpeed > 0 THEN                                 │
│       CycleTime := 3600000 / CurrentSpeed; // ms           │
│   ELSE                                                     │
│       CycleTime := 0;                                       │
│   END_IF;                                                  │
│                                                             │
│   // 角度更新 (每个PROFINET周期)                           │
│   MasterAngle := MasterAngle + (360.0 / CycleTime * 1ms); │
│   IF MasterAngle >= 360.0 THEN                             │
│       MasterAngle := MasterAngle - 360.0;                  │
│   END_IF;                                                  │
│                                                             │
│   ActualSpeed := CurrentSpeed;                             │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 液位PID参数

| 参数 | 数值 | 说明 |
|------|------|------|
| 设定值 | 500ml | 目标液位 |
| 比例系数Kp | 2.0 | 比例增益 |
| 积分时间Ti | 50ms | 积分作用 |
| 微分系数Kd | 0.1 | 微分作用 |
| 控制周期 | 10ms | PID计算周期 |
| 采样周期 | 1ms | 液位检测 |
| 超调限制 | <2% | 防止溢瓶 |
| 稳态误差 | <0.5% | 最终精度 |

### 5.3 液位控制逻辑

```
// 液位PID控制 (10ms周期)

Level_Error := Level_Setpoint - Level_Actual;

// 微分先行PID
P_Out := Kp * Level_Error;
I_Out := I_Out + (Kp/Ti) * Level_Error * 0.01; // 10ms积分
D_Out := Kd * (Level_Error - Level_Error_Prev) / 0.01;

PID_Out := P_Out + I_Out + D_Out;

// 输出限幅
IF PID_Out > 100 THEN
    PID_Out := 100;
ELSIF PID_Out < 0 THEN
    PID_Out := 0;
END_IF;

// 微分先行 - 抑制超调
IF Level_Actual > Level_Setpoint THEN
    PID_Out := PID_Out * 0.5; // 防止超调
END_IF;

// 输出到阀门
Valve_Setpoint := PID_Out;

Level_Error_Prev := Level_Error;
```

### 5.4 液位补偿

| 补偿因素 | 补偿方式 | 补偿量 |
|----------|----------|--------|
| 温度补偿 | 自动补偿 | ±0.1%/℃ |
| 压力补偿 | 自动补偿 | ±0.05%/kPa |
| 液位传感器线性 | 查表补偿 | ±0.5ml |
| 灌装角度补偿 | 固定补偿 | +2ml (倾斜) |

### 6.3 同步控制功能块

```
┌─────────────────────────────────────────────────────────────┐
│              FB_PF_Speed_Sync (速度同步控制)                │
├─────────────────────────────────────────────────────────────┤
│ INPUT:                                                     │
│   - MasterSpeed  : INT    // 主令速度 (B/H)                │
│   - MasterAngle   : REAL   // 主令角度 (°)                 │
│   - FollowSpeed   : INT    // 跟随速度 (B/H)               │
│   - Enable        : BOOL   // 使能信号                       │
│                                                             │
│ OUTPUT:                                                    │
│   - SyncError     : REAL   // 同步误差 (ms)                │
│   - Correction    : REAL   // 校正量 (°)                   │
│   - SyncStatus    : INT    // 0=同步, 1=失步报警           │
│                                                             │
│ IN_OUT:                                                    │
│   - FollowAngle   : REAL   // 跟随角度                      │
│                                                             │
│ LOGIC:                                                     │
│   // 同步计算                                              │
│   PhaseDiff := MasterAngle - FollowAngle;                   │
│                                                             │
│   // 标准化相位差 (-180° ~ +180°)                         │
│   IF PhaseDiff > 180 THEN                                  │
│       PhaseDiff := PhaseDiff - 360;                        │
│   ELSIF PhaseDiff < -180 THEN                             │
│       PhaseDiff := PhaseDiff + 360;                        │
│   END_IF;                                                  │
│                                                             │
│   // 同步误差计算                                          │
│   SyncError := PhaseDiff / 360.0 * CycleTime; // ms        │
│                                                             │
│   // 校正量计算                                            │
│   Correction := SyncError * 0.5; // P校正                  │
│                                                             │
│   // 角度更新                                              │
│   FollowAngle := FollowAngle + (360.0 / CycleTime * 1ms);  │
│   FollowAngle := FollowAngle + Correction;                 │
│                                                             │
│   IF FollowAngle >= 360 THEN                               │
│       FollowAngle := FollowAngle - 360;                    │
│   END_IF;                                                  │
│                                                             │
│   // 失步判断                                              │
│   IF ABS(SyncError) > 2.0 THEN // 超过2ms                  │
│       SyncStatus := 1;                                     │
│   ELSE                                                     │
│       SyncStatus := 0;                                     │
│   END_IF;                                                  │
└─────────────────────────────────────────────────────────────┘
```
