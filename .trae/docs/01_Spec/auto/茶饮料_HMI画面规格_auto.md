## 1. 画面架构

### 1.1 画面导航树

```
SCADA监控系统
│
├── WS-001: 茶饮料生产线总貌 [P0]
│   └── 生产线工艺流程总览、关键参数、报警概览
│
├── WS-002: 水处理系统 [P1]
│   └── 原水、多介质过滤、活性炭、RO、离子交换、UV、纯水储罐
│
├── WS-003: 茶叶萃取系统 [P1]
│   └── 茶叶前处理、三级逆流萃取、茶渣分离、冷却
│
├── WS-004: 过滤净化系统 [P1]
│   └── 碟式离心、超滤膜
│
├── WS-005: 调配系统 [P1]
│   └── 调配罐、糖浆制备
│
├── WS-006: 均质系统 [P1]
│   └── 均质机、阀门组
│
├── WS-007: UHT杀菌系统 [P0]
│   └── 预热、杀菌、保温、冷却、无菌储罐
│
├── WS-008: 灌装系统 [P0]
│   └── 灌装机、旋盖机
│
├── WS-009: 冷却包装系统 [P1]
│   └── 冷却隧道、输送链、贴标机、装箱机
│
├── WS-010: CIP清洗系统 [P1]
│   └── 清洗配方选择、步骤显示、执行控制
│
├── WS-011: 趋势曲线 [P1]
│   └── 历史趋势、实时趋势、多参数对比
│
├── WS-012: 报警汇总 [P0]
│   └── 报警列表、历史报警、报警统计
│
├── WS-013: 产量报表 [P1]
│   └── 日报、周报、月报、自定义报表
│
├── WS-014: 用户管理 [P2]
│   └── 用户列表、权限配置、操作日志
│
├── WS-015: 系统设置 [P2]
│   └── 系统参数、通讯配置、备份还原
```

### 1.2 画面优先级

| 优先级 | 画面数量 | 响应要求 | 说明 |
|--------|----------|----------|------|
| P0 | 4个 | ≤0.5s刷新 | 总貌、UHT、灌装、报警 |
| P1 | 9个 | ≤1s刷新 | 各工段、趋势、报表 |
| P2 | 2个 | 按需刷新 | 用户管理、系统设置 |

## 2. 控件库规格

### 2.1 基础控件

#### 2.1.1 数值显示控件 (NumericDisplay)

| 属性 | 规格 | 说明 |
|------|------|------|
| 控件类型 | NumericDisplay | 数值显示 |
| 字体 | Consolas | 等宽字体 |
| 字号 | 16pt | 主值显示 |
| 小数位 | 1-2 | 可配置 |
| 单位 | 右下标 | 自动附加单位 |
| 颜色 | #FFFFFF/#FFFF00/#FF0000 | 正常/警告/报警 |

#### 2.1.2 液位条控件 (LevelIndicator)

| 属性 | 规格 | 说明 |
|------|------|------|
| 控件类型 | LevelIndicator | 液位显示 |
| 方向 | vertical | 从下往上填充 |
| 高度 | 100px | 标准尺寸 |
| 宽度 | 30px | 标准尺寸 |
| 填充色 | #0066FF | 蓝色 |
| 背景色 | #2a3a5a | 深蓝灰 |
| 高液位 | #FF6600 | 橙色预警 |
| 低液位 | #00CCFF | 浅蓝预警 |
| 超限 | #FF0000 | 红色报警 |

**位置规格**:
```
┌────┐  ← 100% (HH报警线)
│████│
│████│
│░░░░│  ← 液位填充
│░░░░│
└────┘  ← 0% (LL报警线)
```

#### 2.1.3 阀门控件 (ValveSymbol)

| 属性 | 规格 | 说明 |
|------|------|------|
| 控件类型 | ValveSymbol | 阀门状态显示 |
| 形状 | 菱形 | 16×16px |
| 打开状态 | #00FF00 | 绿色填充 |
| 关闭状态 | #808080 | 灰色边框 |
| 故障状态 | #FF0000 | 红色填充 |
| 中间状态 | #FFFF00 | 黄色填充 |
| 开度指示 | 内部百分比 | 数字显示 |

**状态定义**:
```
┌─────────────────────────────┐
│ 状态    │ 颜色   │ 动画    │
├─────────┼────────┼─────────┤
│ 打开    │ 绿色   │ 无      │
│ 关闭    │ 灰色   │ 无      │
│ 打开中  │ 绿色   │ 脉冲    │
│ 关闭中  │ 灰色   │ 脉冲    │
│ 故障    │ 红色   │ 闪烁1Hz │
│ 联锁    │ 黄色   │ 闪烁1Hz │
└─────────────────────────────┘
```

#### 2.1.4 泵控件 (PumpSymbol)

| 属性 | 规格 | 说明 |
|------|------|------|
| 控件类型 | PumpSymbol | 泵状态显示 |
| 形状 | 圆形+三角形 | 24×24px |
| 运行状态 | 绿色+旋转动画 | 25fps |
| 停止状态 | 灰色静态 | 无 |
| 故障状态 | 红色+闪烁 | 1Hz |
| 过载状态 | 黄色+闪烁 | 1Hz |

**旋转动画规格**:
```
运行状态时，显示旋转的三角形标记:
    ▲ → ↗ → → ↘ → ▼ → ↙ → ← → ↖ → ▲
   0°   45°  90°  135° 180° 225° 270° 315°
帧率: 25fps (每帧36°旋转)
```

#### 2.1.5 管道流动控件 (PipelineFlow)

| 属性 | 规格 | 说明 |
|------|------|------|
| 控件类型 | PipelineFlow | 管道流动动画 |
| 管道宽度 | 8px | 标准管道 |
| 液体颜色 | #0066FF | 蓝色 |
| 气体颜色 | #FFCC00 | 黄色 |
| 流动方向 | 沿管道方向 | 虚线移动 |
| 动画速度 | 与流量成正比 | - |
| 静止状态 | 实线 | 无动画 |
