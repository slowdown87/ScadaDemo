## 1. 画面架构

### 1.1 画面导航树

```
SCADA监控系统
│
├── WS-001: 茶饮料生产线总貌 [P0]
│   └── 生产线工艺流程总览、关键参数、报警概览
│
├── WS-002: 水处理系统 [P1]
│   └── 原水、多介质过滤、活性炭、RO、离子交换、UV、纯水储罐
│
├── WS-003: 茶叶萃取系统 [P1]
│   └── 茶叶前处理、三级逆流萃取、茶渣分离、冷却
│
├── WS-004: 过滤净化系统 [P1]
│   └── 碟式离心、超滤膜
│
├── WS-005: 调配系统 [P1]
│   └── 调配罐、糖浆制备
│
├── WS-006: 均质系统 [P1]
│   └── 均质机、阀门组
│
├── WS-007: UHT杀菌系统 [P0]
│   └── 预热、杀菌、保温、冷却、无菌储罐
│
├── WS-008: 灌装系统 [P0]
│   └── 灌装机、旋盖机
│
├── WS-009: 冷却包装系统 [P1]
│   └── 冷却隧道、输送链、贴标机、装箱机
│
├── WS-010: CIP清洗系统 [P1]
│   └── 清洗配方选择、步骤显示、执行控制
│
├── WS-011: 趋势曲线 [P1]
│   └── 历史趋势、实时趋势、多参数对比
│
├── WS-012: 报警汇总 [P0]
│   └── 报警列表、历史报警、报警统计
│
├── WS-013: 产量报表 [P1]
│   └── 日报、周报、月报、自定义报表
│
├── WS-014: 用户管理 [P2]
│   └── 用户列表、权限配置、操作日志
│
└── WS-015: 系统设置 [P2]
    └── 系统参数、通讯配置、备份还原
```

### 1.2 画面优先级

| 优先级 | 画面数量 | 响应要求 | 说明 |
|--------|----------|----------|------|
| P0 | 4个 | ≤0.5s刷新 | 总貌、UHT、灌装、报警 |
| P1 | 9个 | ≤1s刷新 | 各工段、趋势、报表 |
| P2 | 2个 | 按需刷新 | 用户管理、系统设置 |

## 2. 控件库规格

| 属性 | 规格 | 说明 |
|------|------|------|
| 控件类型 | NumericDisplay | 数值显示 |
| 字体 | Consolas | 等宽字体 |
| 字号 | 16pt | 主值显示 |
| 小数位 | 1-2位 | 可配置 |
| 单位 | 右下标 | 自动附加单位 |
| 颜色 | 白/黄/红 | 正常/警告/报警 |

**数据绑定示例**:
```
位号: WT-107-LT
显示: "78.5 %"
颜色: 白色(正常)
刷新: 1s
```

#### 2.1.4 泵控件 (PumpSymbol)

| 属性 | 规格 | 说明 |
|------|------|------|
| 控件类型 | PumpSymbol | 泵状态显示 |
| 形状 | 圆形+三角形 | 24×24px |
| 运行状态 | 绿色+旋转动画 | 25fps |
| 停止状态 | 灰色静态 | 无 |
| 故障状态 | 红色+闪烁 | 1Hz |
| 过载状态 | 黄色+闪烁 | 1Hz |

**旋转动画规格**:
```
运行状态时，显示旋转的三角形标记:
    ▲ → ↗ → → ↘ → ▼ → ↙ → ← → ↖ → ▲
   0°   45°  90°  135° 180° 225° 270° 315°
帧率: 25fps (每帧36°旋转)
```

#### 2.1.5 管道流动控件 (PipelineFlow)

| 属性 | 规格 | 说明 |
|------|------|------|
| 控件类型 | PipelineFlow | 管道流动动画 |
| 管道宽度 | 8px | 标准管道 |
| 液体颜色 | #0066FF | 蓝色 |
| 气体颜色 | #FFCC00 | 黄色 |
| 流动方向 | 沿管道方向 | 虚线移动 |
| 动画速度 | 与流量成正比 | - |
| 静止状态 | 实线 | 无动画 |

**虚线动画规格**:
```
虚线样式: ---->---->---->
移动方向: 与流体方向一致
移动速度: 快=高流量, 慢=低流量
停止条件: 泵停止或阀关闭
```

| Alarm-Tag | Column | Alarm.Tag | 位号 |

#### 4.5.3 报警统计规格

| 统计维度 | 计算方式 |
|----------|----------|
| 按等级统计 | COUNT(今日报警, GROUP BY Level) |
| 累计时长 | SUM(报警持续时间) |
| 平均响应时间 | AVG(确认时间 - 触发时间) |
| 班组统计 | 按班次分组统计 |

## 5. 交互规格

### 5.1 鼠标交互

| 操作 | 目标控件 | 响应 |
|------|----------|------|
| 单击 | 工艺设备符号 | 跳转对应工段画面 |
| 单击 | 参数数值 | 弹出趋势小窗口 |
| 双击 | 参数数值 | 跳转趋势画面(该参数) |
| 单击 | 报警条 | 跳转报警详情 |
| 右键 | 设备符号 | 弹出操作菜单 |
| 悬停 | 设备符号 | 显示设备详情tooltip |

### 5.2 键盘快捷键

| 快捷键 | 功能 |
|--------|------|
| Esc | 取消当前操作/关闭弹窗 |
| Enter | 确认当前操作 |
| F1 | 帮助 |
| F5 | 刷新当前画面 |
| Ctrl+F | 搜索 |
| Ctrl+P | 打印 |
| Ctrl+A | 全选(列表) |
| 1-9 | 快速跳转画面 WS-00X |

### 5.3 权限验证

| 操作 | 权限检查 | 无权限响应 |
|------|----------|------------|
| 设备启动 | 等级≥1 | 按钮禁用+提示"需要操作员权限" |
| 参数修改 | 等级≥4 | 输入框禁用 |
| 配方调整 | 等级≥3 | 按钮禁用 |
| 用户管理 | 等级≥5 | 菜单隐藏 |
