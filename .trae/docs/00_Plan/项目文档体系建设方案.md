## 1. 概述

### 1.1 目的

本文档定义茶饮料生产线 SCADA 项目的完整文档体系建设方案，明确各类文档的生成方式、责任划分和技术可行性。

### 1.2 项目背景

本项目为**纯茶饮料（绿茶/红茶/乌龙茶）生产线**配套的SCADA监控系统，产能50000B/H（额定）/ 54000B/H（最大），采用PET瓶热灌装工艺。

### 1.3 生产线工段划分

根据饮料生产线行业实践，本项目分为**14个独立控制工段**：

| 序号 | 代码 | 工段名称 | 控制特点 | PLC配置 |
|------|------|----------|----------|---------|
| 1 | WT | 水处理 | 公用工程，24h运行 | PLC-1 |
| 2 | TH | 茶叶前处理 | 粉碎、输送、防爆 | PLC-2 |
| 3 | EX | 萃取 | 批次控制，温度控制 | PLC-3 |
| 4 | BL | 调配 | 批次控制，Brix/pH | PLC-4 |
| 5 | HM | 均质 | 压力控制 | PLC-5 |
| 6 | UH | UHT杀菌 | **CCP关键控制**，温度曲线 | PLC-6 |
| 7 | BF | 制瓶 | 高速同步，模具控制 | PLC-7 |
| 8 | PF | 灌装 | **超高速同步**，72ms/瓶 | PLC-8 |
| 9 | CG | 旋盖 | 扭矩控制，速度同步 | PLC-9 |
| 10 | LI | 灯检 | 视觉检测，独立控制 | PLC-10 |
| 11 | CI | 喷码 | 日期/批次打印 | PLC-11 |
| 12 | LB | 贴标 | 标签位置控制 | PLC-12 |
| 13 | CA | 装箱 | 纸箱成型，计数 | PLC-13 |
| 14 | PK | 膜包+码垛 | 热缩包装，堆叠 | PLC-14 |

## 3. 文档分类原则

| 类别 | 定义 | 生成方式 |
|------|------|----------|
| **结构化文档** | 以文本/数据为主，可标准化 | YAML模板 → 自动生成 |
| **工程图纸类** | 需要CAD软件绘制 | 提供规范/清单，不能自动生成CAD |
| **工艺控制文档** | 各工段控制逻辑、顺序、参数 | 模板化，需人工编写详细内容 |

## 4. PLC架构设计（待修正）

### 4.1 当前问题

当前PLC_Architecture.md存在以下问题：

| 问题 | 说明 |
|------|------|
| PLC数量不足 | 仅设计了3个PLC，实际需要14个 |
| 控制负载不均 | UHT+灌装放在同一PLC，负载过重 |
| 脱离行业实践 | 应该每个工段独立或合理分组 |

### 4.2 推荐架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                         SCADA监控层                                 │
│                    (服务器 + 操作站 + 工程师站)                      │
└─────────────────────────────────┬───────────────────────────────────┘
                                  │ 工业以太网
          ┌───────────────────────┼───────────────────────┐
          │                       │                       │
┌─────────┼─────────┐ ┌─────────┼─────────┐ ┌─────────┼─────────┐
│ PLC-1   │ PLC-2   │ │ PLC-3   │ PLC-4   │ │ PLC-5   │ PLC-6   │
│ 水处理   │ 茶叶前处理│ │ 萃取     │ 调配     │ │ 均质     │ UHT     │
│ WT      │ TH      │ │ EX      │ BL      │ │ HM      │ UH      │
└─────────┴─────────┘ └─────────┴─────────┘ └─────────┴─────────┘

┌─────────┼─────────┐ ┌─────────┼─────────┐ ┌─────────┼─────────┐
│ PLC-7   │ PLC-8   │ │ PLC-9   │ PLC-10  │ │ PLC-11  │ PLC-12  │
│ 制瓶     │ 灌装     │ │ 旋盖     │ 灯检     │ │ 喷码     │ 贴标     │
│ BF      │ PF      │ │ CG      │ LI      │ │ CI      │ LB      │

┌─────────────────────────┐ ┌─────────────────────────┐
```

### 4.3 PLC职责分配

| PLC | 工段 | 主要控制任务 | I/O估算 | 备注 |
|-----|------|-------------|---------|------|
| PLC-1 | WT水处理 | 液位、流量、水质监控 | ~200点 | 公用工程 |
| PLC-2 | TH茶叶前处理 | 粉碎、输送、除尘 | ~100点 | 防爆区域 |
| PLC-3 | EX萃取 | 顺序控制、温度、tea ratio | ~180点 | 批次控制 |

### 7.1 电控柜设计（⚠️ 部分可自动生成）

#### 7.1.1 内容范围

| 图纸类型 | 内容 | 自动生成可行性 |
|----------|------|---------------|
| 电气原理图 | 主回路、控制回路 | ❌ 无法生成CAD |
| 端子接线图 | 端子排定义、线号 | ✅ 可生成清单 |
| 柜内布置图 | 元器件排列 | ❌ 无法生成CAD |
| 电缆清单 | 电缆规格、起点终点 | ✅ 可生成清单 |
| I/O清单 | 模块配置、地址分配 | ✅ 已从点表生成 |

#### 7.1.2 可自动生成的内容

**元器件清单**（从监控点表和设备清单派生）：
- PLC模块配置清单
- 电源、继电器规格清单
- 端子排定义表

**电缆清单**（部分）：
| 线缆编号 | 起点 | 终点 | 规格 | 长度 | 用途 |
|----------|------|------|------|------|------|

| C002 | PLC-1柜 | WT-102现场箱 | KVVP 4×1.5 | 55m | 流量信号 |

#### 7.1.3 不能自动生成的内容

| 图纸类型 | 原因 |
|----------|------|
| 电气原理图 | 需要专业电气设计知识、CAD软件 |
| 柜内布置图 | 需要根据实际柜体尺寸规划 |
| 端子接线图 | 需要结合现场实际情况 |

#### 7.1.4 建议方案

**电控柜设计采用 EPLAN 或 AutoCAD Electrical，需要专业电气工程师完成。**
