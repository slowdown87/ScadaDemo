## 📋 文档分类说明

| 目录 | 文档类型 | 说明 | 编辑方式 |
|------|----------|------|----------|
| 00_Plan | 规划文档 | 项目计划、状态追踪 | 手动 |
| 01_Spec | 规格文档 | 系统/软件需求规格 | 手动 |
| 02_Arch | 架构文档 | 技术架构设计 | 手动 |
| 03_Device | 设备文档 | 设备清单、位号定义 | 模板生成+手动 |
| 04_Process | 工艺文档 | 工艺参数、CIP、联锁、通讯、工段控制 | 工段控制手动，其他模板生成 |
| 05_Product | 产品文档 | 产品配方、CIP配方 | 模板生成 |
| _templates | 模板文件 | YAML/MD源数据 | **仅手动修改** |
| _generators | 生成器 | Python代码 | 手动修改 |

## ⚙️ 维护规则

### 1. 模板文件修改流程

```
1. 修改 _templates/*.yaml 模板文件（唯一正确入口）
2. 运行 _generators/*.py 生成器
3. 检查生成的 *_auto.md 文档
4. 提交 _templates/ 和 _generators/（不提交auto文件）
```

### 2. 工段控制规格文档

工段控制规格文档（WT_xxx.md等）**手动编辑**，不受生成器影响。
当设备变更时，需同步更新：
- devices.yaml（设备定义）
- 对应工段控制规格.md（控制逻辑）

### 3. 版本更新规则

| 文档类型 | 更新时机 | 版本号规则 |
|----------|----------|------------|
| 模板文件 | 修改源数据后 | v1.0 → v1.1 |
| 生成文档 | 重新生成后 | 自动更新日期 |
| 手工文档 | 内容重大变更 | v1.0 → v2.0 |
| 工段控制规格 | 控制逻辑变更 | v1.0 → v1.1 |
