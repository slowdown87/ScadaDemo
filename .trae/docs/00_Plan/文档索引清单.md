## 📋 文档分类说明

| 目录 | 文档类型 | 说明 |

| 00_Plan | 规划文档 | 项目计划、状态追踪 |

## ⚙️ 维护规则

### 1. 模板文件修改流程

```
1. 修改 _templates/*.yaml 模板文件
2. 运行 _generators/*.py 生成器
3. 检查生成的 *_auto.md 文档
4. 提交模板文件(不要提交auto文件)
```

### 2. 手工文档修改

- 直接编辑对应的 `.md` 文件
- 更新文档版本的 `版本历史` 章节

### 3. 新增文档

- 手工文档放到对应分类目录
- 模板文件放到 `_templates/`
- 更新本文档的目录结构
